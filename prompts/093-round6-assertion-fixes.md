# 093 第六轮脚本假失败收敛

## 背景

092 给出的完整脚本落位后首次实跑，45 条里 39 通过 6 失败，两条金丝雀按预期报差异。
失败全部集中在断言自身的判据，产品代码没动过一行。

## 本机已核验事实

超长标题用例把一段原文里根本不存在的长标题传给了定位函数，而且传的是完整长标题不是带省略号的显示值。
单 token 用例拿两个对象做严格相等比较，对象永远不相等。
批量清标记用例用整文件第一个匹配位置判断先后顺序，取到的是选中通知那一处。
两个结束时间用例用带冒号的正则找返回对象，而返回对象里是简写属性没有冒号。
还有一条检查写成源码里有换行，任何源码都满足，属于假绿。

## 验收要点

第一，六条报红全部改成真能承重的判据，不许把期望值改成实际值了事。
第二，假绿那条换成能区分字面反斜杠与真换行的精确判据。
第三，删掉没用上的变量。
第四，只给成对替换片段，别重写整文件，别动生产代码，别动金丝雀。

## Prompt

```
新脚本我照着放进去跑了，四十五条里有六条报红，两条金丝雀倒是按预期报差异了。我把报红的几条抄下来了。超长标题那两条说定位不到，我回头看了一下，测试里那段长标题根本没放进原文，而且传给定位函数的是完整长标题，不是界面上带省略号的那串。单 token 那条两个对象比不出来，显示都是一串看不懂的字。批量清标记那条说顺序不对，我猜它找的是文件里第一处清标记，不是确认切分里的那一处。两个结束时间那条也说找不到，可返回对象里明明写着，好像是简写没带冒号。另外还有一条检查写的是源码里有换行，我觉得这个不管怎么改都会过，等于没检查，能不能一并换成真的能盯住那处换行的写法。还有个没用上的变量也顺手删掉。请只给要改的那几段，别把别的断言放宽，也别动生产代码。
```
