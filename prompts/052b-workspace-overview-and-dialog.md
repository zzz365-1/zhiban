# 052b 第四轮之三 工作台首页、新增通知弹窗与顶部条

## 背景

导航和事项卡片已经好了。这一步把工作台的主页面、新增通知的弹窗、还有顶部那条搜索栏做出来。
新增通知做成弹窗，是为了不再让每个页面都挂一个大输入框。

## 几条硬约束

第一，只新建文件，不动现有文件。

第二，三个组件都复用已有通用组件与图标，不另起炉灶。

第三，工作台显示的是真实数据，不许写死假数字。
