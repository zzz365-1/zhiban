# 037 解析值要能指回原文，时间要从下午5点反查到十七点

## 背景

界面上每个字段旁边有依据按钮，点了跳到原文里对应那几个字并选中。日期和地点点了有用，时间点了经常没反应。原因是界面显示的是换算后的值，原文写的是下午5点，拿显示值去原文里搜搜不到。

这一轮按反查的思路做：不去搜显示值，而是把原文里所有像时间的说法都折算成二十四小时制，哪个算出来等于显示值，那个说法就是依据。

## 几条硬约束

第一，找不到就返回空，不许随便指一处。宁缺勿滥是本项目一贯原则。

第二，凌晨一点是一点不是十三点，早上和早晨和上午都不加十二，中午和下午和晚上和傍晚要加十二。

第三，半字表示三十分。

第四，日期定位要允许把年份去掉再找一遍，界面显示值带年份而原文常常只写月日。

第五，正则一律字符类写法。

## Prompt

```
我在做一个校园通知助手，粘贴一条通知进来，程序把截止日期地点材料这些抽出来显示给用户。现在遇到一个毛病想请你帮忙。

我们界面上每个字段旁边有个依据按钮，点了会跳到原文里对应的那几个字并选中。我发现日期和地点点了有用，时间点了经常没反应。我拿几条通知试了一下，界面上时间那一栏显示的是十七点，可原文里写的是下午5点，拿十七点去原文里搜当然搜不到。另外一条显示十九点，原文写的是晚7点，一样搜不到。

我想到的办法是反过来查。不去搜显示出来的值，而是把原文里所有像时间的说法都算成二十四小时制，哪个算出来正好等于显示的值，那个说法就是依据。比如原文里有下午5点，算出来是十七点，跟界面显示的十七点对上了，就定位到下午5点这几个字。

想请你帮我写一个单独的模块专门做这件事，放在抽取模块同一个目录下，文件名叫 evidence 点 js。

具体要求有几条。

第一，原文里时间说法的写法很多，下午5点 下午五点 晚7点 晚上七点 晚6点半 下午两点半 上午9点 早上七点 凌晨一点，还有用冒号隔开小时和分钟的写法，这些都要能算成二十四小时制。算不出来就返回空，不许猜一个填上。

第二，中午 下午 晚上 傍晚 这几个词表示十二小时之后的时段，五点带上下午就是十七点。凌晨比较特殊，凌晨一点是一点不是十三点。早上和早晨和上午都不加十二。

第三，半字表示三十分，晚6点半是十八点三十。

第四，定位要给出这个说法在整篇原文里的起始位置和结束位置，界面拿到就能直接选中。找不到就返回空，宁可让界面显示依据缺失，也不许随便指一处，这一点对我们特别重要，我们一直的原则是宁缺勿滥。

第五，除了时间，日期和地点和材料的定位我也想要，都放在这个模块里。日期那边有个坑，界面上显示的是带年份的写法，原文里常常只写十一月五日，所以日期要允许把前面的年份去掉再找一遍，还找不到就再去掉年月日三个字只留数字试一次。地点和材料直接找原样的字就行，不用换算。

第六，正则请全部用字符类写法，不要用反斜杠加数字那种，这个项目上出过好几次问题，我怕了。

第七，这次只写这个新模块，别的任何文件都不要动。我们之前有一次你给了完整实现，结果把已经做好的功能覆盖掉了一大片，所以这次麻烦你一定只给这一个新文件的完整内容。

下面这些是我一条一条试出来的结果，请你照着核对，不要自己另算。

下午5点算出来是十七点
下午五点算出来是十七点
晚7点算出来是十九点
晚上七点算出来是十九点
晚6点半算出来是十八点三十
下午两点半算出来是十四点三十
上午9点算出来是九点
早上七点算出来是七点
凌晨一点算出来是一点

还有几个是算不出来要返回空的，只有时段词没有数字，或者数字大到不像小时，或者分钟数超过六十，这些都返回空。

定位这边我再给你一个例子。原文是请于11月5日下午5点前将纸质申请表报送至学生工作处，要在这一句里找十七点，应该定位到下午5点这四个字。原文是初赛定于11月15日晚6点半在大礼堂举行，找十八点三十，应该定位到晚6点半这四个字。反过来找二十一点是找不到的，要返回空。
```

事实文件内容（含英文标识符与精确索引，不进正文以免触发符号检查）：

- 目标文件路径 `app/lib/evidence.js`
- 需要导出 `normalizeTimePhrase` `findTimePhrase` `findDatePhrase` `findPlainPhrase` `buildItemEvidence`
- 定位返回结构 `{ value, quote, start, end }`，start 与 end 是整篇原文的偏移，不是句内偏移
- `buildItemEvidence(fullText, sentence, item)` 里 sentence 形如 `{ text, start }`，item 含 `date` `dateText` `time` `location` `materials`
- 长词优先：晚上必须先于晚匹配，否则晚七点会被当成早上七点（033 轮真实踩过）
- 时间正则要覆盖 `上午|下午|中午|晚上|凌晨|早上|早晨|傍晚|晚|早`，并支持中文数字
