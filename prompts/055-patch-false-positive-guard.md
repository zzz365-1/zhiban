# 055 第四轮验收中发现 普通通知被误判为补充通知

## 背景

第四轮真浏览器验收时，载入示例之后粘贴一条完全正常的助学金通知点解析，
程序却弹出请选择它要修改的原通知，也就是把普通通知当成了补充通知。
本机取证发现是通知里的逾期不再受理触发了取消词，还顺带把下午5点前当成时间变更抽了出来。
这会直接让新增通知和解析走不通，必须先修掉再继续验收。

## 几条硬约束

第一，真正的补充通知仍然要能识别。

第二，歧义那两条老用例一条都不许坏。

第三，补回归用例，并且要 import 生产模块。

第四轮验收的时候我碰到一个很烦的问题，请你帮我修一下，只改一个小地方。

事情是这样的。我先载入了示例通知，然后粘贴了一条很普通的助学金通知点解析，结果页面弹出来一块请选择它要修改的原通知，也就是说程序把这条普通通知当成了补充通知，普通解析压根走不下去。这条通知的原文我抄在下面，就是三行。

关于2026年国家助学金评审工作安排的通知
各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室，逾期不再受理。
评审会定于11月8日晚7点在行政楼A302会议室召开，请各班班长届时到场。

我在本机把抽取函数单独跑了一遍，结果它是这样的。它说这是一条补充通知，还抽出来两条变更，一条是取消，依据原句就是带逾期不再受理那一整句，另一条是时间改成十七点，依据原句还是那一整句。两条都不对，逾期不再受理只是原通知里常见的收件说明，说的是过期不收材料，不是说某个活动取消了，下午5点前也只是原本的截止时间，不是什么新改的时间。

我猜是词表里那个不再被命中了，把整句判成了变更句，然后这句里的时间又被当成新值抽了出来。请你先确认一下是不是这个原因，如果不是就按你查到的真实原因修。

我要你做的事情是这样。请在判断一句话是不是变更句那一段加一层过滤，让逾期不再受理，不再受理，不再接收，不再接受，逾期不再，过期不再 这类收件说明里的不再不算变更词。注意我的意思是这些固定说法里的不再不算，不是把不再这个词整个从词表删掉，真正说不再举行不再举办这种还是要能识别成取消。请实现得窄一点，只把这几组固定说法排掉，不要顺手扩成一张大黑名单，之前我们吃过通用动作词黑名单误伤单位名的亏。

修完以后这条普通助学金通知应该被判成不是补充通知，变更数组应该是空的。

另外有几条底线请你务必守住。

第一，真正的补充通知还得照常识别。比如这条，补充通知，原定11月8日的助学金评审会调整至11月9日十九点，地点改为行政楼B201会议室，其余安排不变。它应该还是补充通知，变更里应该至少有日期和地点两项，其余安排不变这个意思也要保留下来。

第二，现有测试里那两条歧义用例一条都不许坏。一条说评审会时间另行通知，要记进歧义，一条说有歧义时不许落盘，变更数组长度要是零。这两条原来就是过的，改完还得是过的。

第三，测试代码要直接引用真正的那个模块，不要自己另外抄一份相似的判断。

第四，请顺手在测试脚本里补两条回归用例。第一条就用上面那条三行助学金原文，断言它不是补充通知并且变更数组长度为零。第二条用上面那条真的补充通知，断言它是补充通知并且变更里同时有日期和地点这两个字段。这两条用例都要走真正的抽取函数。
