# 089 模型字段被丢与来源标签不一致

## 背景

含报名截止日与活动举办日的通知，本地规则只认出截止日，指望模型补活动日期和时间，
结果界面里活动日期活动时间两行一直不出现。另外同一条本地规则识别的通知，
列表和顶部写手动导入，右侧解析面板写本地规则识别。

## 本机已核验事实

提示词明确要求模型输出活动日期 活动时间 活动结束时间，但服务端返回给前端的结果只保留八个字段，
三个字段全被丢掉。合并函数会读模型给的活动日期和活动时间，最后返回的对象却没有结束时间字段。
给模型的示例和正文之间是字面的反斜杠加字母，不是真正的换行。
本地命中时来源值是 rule，来源标签函数只处理手动修正 模型补充 本地识别三种，rule 落到默认的手动导入。

## 验收要点

第一，服务端结果补齐活动日期 活动时间 活动结束时间 截止结束时间。
第二，合并函数返回对象补上两个结束时间字段，本地值优先。
第三，示例与正文之间是真正的换行。
第四，rule 与本地识别回落都显示本地识别，其余来源标签不变。
第五，只输出改动片段，不动抽取规则与出处核对。

## Prompt

```
我发现两个小地方说不通。第一个是我写了一条通知，前面是报名截止，后面又写了活动哪天举行几点开始几点结束，本地规则只认出了截止那天，我本来指望模型帮我把举办日和结束时间补上，可是解析结果里活动日期和活动时间两行一直不出现。我翻了翻给模型看的提示词，里面明明要求它输出这些字段，我猜是中间哪一步把值丢了吧。第二个是我明明没有手动改过任何东西，一条通知完全靠本地规则认出来，左侧列表和顶部却写着手动导入，右边解析面板又写着本地规则识别，同一条通知两处说法不一样，老师问我我都答不上来。还有给模型的示例和正文之间显示成了反斜杠加字母，不是空行，不知道会不会影响它理解。能不能帮我看看这几个地方，只改需要改的片段，别把别的字段弄丢了。
```
