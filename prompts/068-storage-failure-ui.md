# 068 第六轮自检 保存失败界面没有任何提示

## 背景

第六轮异常验收时，我在浏览器里人为让本地存储写入抛错，
然后粘贴一条通知解析并点保存到我的通知。
结果是界面上照旧显示已保存，通知条数从零变成一，
但那条数据其实根本没写进本地存储，刷新就会丢。
用户会以为已经存好了，这比直接报错更糟。

本机取证：异常脚本返回 hasSaveErrorTip 为假，界面全文里没有保存失败或保存本地这类字样，
状态标签是已保存，输入框里的原文还保留着。

## 已核验事实

页面主文件里有一个副作用，在通知数组或初始化状态变化时把数组写进本地存储。
写入那段的异常分支里只有一句控制台警告，没有把错误抬到界面上。
界面上通知的状态字段是在内存里改的，所以照旧显示已保存。

## 验收要点

第一，本地存储写入失败时，界面上要有一条明确的错误提示，
不能让用户以为已经存好了。

第二，通知原文和解析结果要原样保留，不能因为保存失败就清空。

第三，要给一个能当场重试的入口，重试成功之后错误提示要消失。

第四，正常保存时不能冒出这条错误提示，原有功能一条都不能受影响。
