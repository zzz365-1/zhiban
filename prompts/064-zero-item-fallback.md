# 064 第一轮自检 要办事的通知拆出零个事项

## 背景

第一轮自检时，用一批没有参与过开发的新通知跑生产模块，
有两条明确要求办事的通知，程序返回零个事项，界面上是空的。

第一条是关于实验室安全自查的通知，
请各实验室对照检查表完成自查，发现问题及时整改。

第二条是毕业生图像采集通知，
毕业生须于11月8日至11月10日每日9点00到16点00携带本人身份证和学生证到体育馆一层完成采集。

第二条其实信息很全，有日期有时间有地点有材料，
就因为句子里没有分类词表里的词，整条通知一个事项都没拆出来。
用户拿到手是一个空白页，不知道自己要干什么，
这一条直接违背把校园通知变成清晰行动这个目标。

## 本机已核验事实

事项切分模块里，分类由一个函数按句判断，
它手里有两张词表，一张是手续类，一张是活动类。
两张表里都没有自查，整改，采集，携带，完成这类词，
所以这两条通知的每一句都返回空，后面就没有任何事项产出。
模块里目前没有兜底逻辑，句子全部分类失败就是零个事项。

## 验收要点

第一，那两条通知都要至少生成一个事项，第二条要带上日期时间地点材料。

第二，原来能正常分类的通知一条都不能受影响。

第三，纯告知类通知不能硬造出事项来，比如只是通报某位老师获奖。

第四，抽不到的字段要留空并标明原因是原文未提及。

第五，改完跑全量回归，所有离线命令都要过。

## Prompt

```
我发现我的程序还有个毛病，有些通知一个事项都拆不出来，界面上是空的，用户不知道自己要干什么。

我试了两条。第一条是，关于实验室安全自查的通知，请各实验室对照检查表完成自查，发现问题及时整改。第二条是，2027届毕业生图像采集通知，毕业生须于11月8日至11月10日每日9点00到16点00携带本人身份证和学生证到体育馆一层完成采集。这两条其实都是要办事的，但程序返回零个事项。

我猜是分类用的关键词表里没有自查整改采集携带这类词，所以每个句子都没被分上类。能不能帮我做两件事。

第一，把这类常见的办事动词补进词表，比如自查，整改，采集，体检，报到，核验，排查，演练这些，你觉得还缺什么也一起补上，但是要小心别把纯告知类的通知也判成要办事的。

第二，加一个兜底。如果整条通知里一个句子都没被分类成功，但是原文里明显有要办事的说法，比如出现了请字加动词或者须于这种写法，就至少生成一条事项。日期时间地点材料能抽多少算多少，抽不到的字段留空并且标明原因是原文未提及。

有几条请你严格守住。第一，原来能正常分类的那些通知一条都不能受影响。第二，纯告知类的通知不要硬造出事项来，比如只是通报某位老师获得了某个奖项，或者只是说某个系统上线了，这种不该有事项。第三，正则请一律用字符类，不要出现反斜杠加数字的写法。第四，只改事项切分这一个模块，别的模块不要碰。

请只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。改完我本机跑全量回归，跑不过再回来找你。
```
