## Prompt 正文（可直接复制）

> 写作原则（本助手内部准则，不随 Prompt 发出）：
> 1. 以参赛学生本人的第一人称视角叙述，语气接近真人，禁止甲方需求文档口吻
> 2. 刻意不预设只有资深工程师才知道的技术细节（具体次版本号、新特性稳定性判断等），把选型判断交还给 DeepSeek
> 3. 技术要求用陈述句直接下达，不要一路追问
> 4. 适度示弱但不夸大，不使用"完全没做过"这类经不起推敲的表述
> 5. **不使用任何中括号小标题**，全部揉进自然段落
> 6. 人设定位：**计算机专业大二学生**——承认科班背景，如实说明缺实战。术语可用但不卖弄，不装外行也不装架构师

```
你好，想请你帮我搭一个网页项目的初始骨架，我一步一步跟着你做。

我是计算机专业大二学生，课内学过一些基础，但完整地搭一个网页项目还是头一回，
所以麻烦你讲得具体一点，最好每一步都告诉我要做什么。

我要做一个叫"知办"的校园通知助手。想法是：同学平时会收到各种各样的校园通知，散落在
群聊、公众号、教务系统里，很容易漏掉截止时间。我想做一个工具把这些通知整理清楚，自动
找出截止时间、地点这些关键信息，再变成待办和日历事项。现在我处在最开始的一步，只想
先把项目跑起来，在浏览器里能看到"知办"两个字就行，功能后面慢慢加。

我这边的环境是 Windows 电脑，Node.js 装好了版本是 v26.13.0，npm 是 11.20.0。项目放在
D:\zhiban 这个文件夹里，里面已经有 docs、prompts、deliverables 三个子文件夹了，
这几个不要动。

技术这块你帮我拿主意，我有几个要求：用 Next.js，听说做这种带后台功能的小应用比较合适，
版本就用现在最稳定的那个；页面样式我听说有 Tailwind 这类工具，你按现在最主流的做法来，
顺便告诉我怎么用；另外请把每个文件的完整代码都贴出来，我会直接在 VS Code 里一个个
新建文件粘进去保存，不用命令行脚手架那种方式，我对那种操作不熟，出问题不好收拾。

第一个页面不需要好看，中间显示"知办"两个字，下面一行小字"校园通知行动助手"，
看得清楚就行。

还有件事，我这个项目后面要用 Git 做版本管理，听说有些文件不该传上去，这块你比我懂，
顺手帮我处理一下。

最后麻烦告诉我：文件都保存好之后，我该敲什么命令把它跑起来，怎么确认它成功了。谢谢！
```
