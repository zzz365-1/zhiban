# 026 下半区网格空出一列

## 背景

022 把页面改成上下结构之后，我打开主页那个文件看了一下，发现下半部分的网格写了三列，
但是里面只放了两个东西，第三个格子没有任何内容占着。也就是说屏幕右边空了一整块，
宽度白白浪费了。022 本来要解决的就是宽度分配失衡，现在这个失衡还留着一半。

本轮只修这一处，不动抽取逻辑，不动测试。

## Prompt

```
我又发现一个问题想请你帮忙。

上次你帮我把页面改成上下结构之后，我打开主页那个文件看了一下，发现下半部分那个网格还是有点不对。我看到的那一行的意思是横向分三格，第一格固定二百六十像素，后面两格各占剩下的一半。可是网格里面只放了两个东西，左边一个是通知列表或者待办或者日历，右边一个是显示解析结果的那个组件。第三个格子没有任何东西占着。

结果就是在宽屏上右边空出来一大块，看着像没做完。我记得这次改布局要解决的本来就是宽度分配不合理的问题，现在这个问题只解决了一半，空的那一格还在。

我想请你把这块改好。我的想法是让显示解析结果的那个组件横跨后面两格，这样左边还是那个窄列表，右边结果区能占满剩下的宽度，里面的字段还是按两列排。如果你觉得把网格改成只分两格更合适，也可以，你按你的判断来。只要保证宽屏下右边不空一大块就行。

我有几个地方想提醒你。第一个是只改这一处，不要把通知列表那些组件也一起改了，也不要动抽取相关的任何文件。第二个是不要删掉任何现有功能，解析结果面板里的手动修改，字段高亮，失败原因提示这些都还要在。第三个是不要新增任何依赖。第四个是项目里没有配置路径别名，引用模块要写相对路径。

回复的时候不要把这个文件整个重新输出一遍，只要告诉我改动落在哪几行，把改之前和改之后的那几行分别写出来，我自己去替换。如果改动分散在好几处，就一处一处分开说清楚，每处都标明大概在第几行。

我不太懂页面布局怎么写的，如果哪里说得不对，你按你的判断来就好。
```

## 验收要点（本机侧）

1. 改动只落在主页文件与结果面板组件，抽取模块与测试脚本零改动
2. 网格声明的列数与实际子元素占用的列数一致，不存在空格子
3. 结果面板内部字段仍为两列排布，材料一格仍独占整行
4. 手动修改、字段高亮、失败原因横幅三处渲染逻辑未被删除
5. 全量 18 条离线命令 exit=0
