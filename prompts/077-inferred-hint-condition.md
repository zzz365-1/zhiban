# 077 收紧模型换算提示的开关，别在原文词旁边说换算过了

## 背景

075 与 076 加好通知发布日期入口之后，1280 截图复核发现一处会讲错的文案。
留空不填时，截止日期那一格显示的还是「下周三」，底下却同时挂着两句橙色提示，
第一句说「原文为相对日期，这里是模型按今天日期换算的结果，仅供参考」，
可是值根本没换算，这句是错的，会让看的人以为程序偷偷按今天算过了。

## 本机已核验事实

`AnalysisPanel.js` 里 `showInferredHint` 只看 `analysis._inferredDeadline`，
只要模型参与过就为真，不管最终显示的日期是不是具体日期。
`showPendingDateHint` 是另一个开关，看 `_datePending`，这句是对的，必须保留。

`app/lib/aiExtract.js` 导出了 `isFuzzyDate`，本机实测，
「下周三」「明天」判真，「2026年11月11日」「11月5日」判假。
`AnalysisPanel.js` 本来就从这个文件导入过别的函数，可以直接补进现有的导入语句。

## Prompt

```
昨天加的通知发布日期入口已经能用了，填上日期之后下周三会变成具体日期，橙色提示也没了。可是我今天截图又发现另一处别扭。

留空不填的时候，截止日期那一格显示的还是下周三，底下却同时挂着两句橙色的字。一句说原文为相对日期这里是模型按今天日期换算的结果仅供参考，另一句说日期待确认请补充发布日期以便换算。第一句明显不对，值明明还是下周三，根本没换算成什么结果，说按今天换算会让看的人以为程序偷偷算过了。

我本机查了一下，界面组件里那句提示的开关只看一个标记，只要模型参与过就亮，不管最后显示出来的那个日期到底是不是具体日期。同一个文件里还有一句待确认提示是单独一个开关，那个是对的，得留着。库里有个判断日期是不是模糊说法的函数，下周三明天会判真，2026年11月11日和11月5日会判假，组件本来就从那个文件导入过别的函数。

能不能帮我把第一句提示的开关收紧一下，只有在截止日期那一格显示出来的确实是具体日期的时候才亮。显示下周三明天这种原文词的时候，只留待确认那一句，别再说模型按今天换算了。

我特别在意几件事。第一，待确认那句提示一个字都不要动，现在界面上真的有地方能填发布日期了，这句要留着引导用户。第二，填上发布日期之后具体日期正常显示，那句模型换算的提示如果条件满足也照常，不要干脆删掉整个提示。第三，别动解析逻辑，别动抽取，别动事项，只改这一个开关。第四，只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。正则请一律用字符类，不要出现反斜杠加数字。

改完我本机跑全量回归，跑不过再回来找你。
```
