# 036c 输入框四周留白填装饰底图

日期：2026-11-02
模块：`app/page.js`、`app/components/NoticeInput.js`、
新增 `public/input-decor.svg`、`design/input-decor.drawio`

## 背景

同学说输入框四周有点空，想要一张精致的图把四周填满。这台电脑上没有装 draw.io，
装它要另外下载一百多兆还要他点一次权限，他选了让我直接手写，先能看效果。

我先看了一眼布局才动手。输入区外面套了一层最大宽度限制，
屏幕一宽，输入框左右就各空出一大片，这才是空的真正位置。
所以底图要铺在整块区域上，不能铺在输入框里面，
而且图案要往两边靠，中间刻意留空，不然会被输入框整个盖住等于白画。

## Prompt

```
同学说输入框四周看着有点空，想要一张精致的图把四周填满，我想请你帮我画一张装饰底图。

先说一下我这边的布局，免得你画的东西被挡住。输入区整块是宽度铺满的，
高度占右列百分之四十五，里面套了一层最大宽度限制，所以屏幕一宽，
输入框左右两边各会空出一大片，我要填的就是这两片。

我想请你这样安排。底图做成宽一点的横幅，比例大概是三比一。
四个角各放一个跟校园通知有关的小图标，左上是日历，右上是铃铛，
左下是剪贴板，右下是时钟。左边靠上放一个喇叭，右边靠下放一个文档。
中间那一片请刻意留空，最多放几个很淡的小圆点，不要放大图，
因为中间会被输入框盖住，画了也看不见。

风格上我想要淡蓝色系的细线图标，背景是浅蓝到白的渐变，
再加几个半透明的大光斑和一点点圆点纹理，还有一两条很淡的虚线曲线。
整体要清透，不能抢输入框里文字的位置，图标颜色一律用淡蓝，不要用深色。

格式要 SVG，纯代码不要引用外部图片，也不要用外部字体，
这样放到项目里不依赖网络。宽高请写死，背景自己带一层渐变底色。

麻烦你直接给我完整的 SVG 代码，我会放到项目的静态资源目录里，
用背景铺满的方式铺在输入区那块。
```

## 结果

图是 1600 比 480 的横幅，6.2 KB，纯代码不依赖网络。
四个角分别是日历 铃铛 剪贴板 时钟，左边喇叭，右边文档。
底色是浅蓝到白的渐变，加了两个半透明光斑，一层淡圆点纹理，两条虚线曲线。

铺法是把底图放在输入区最外面那一层，背景铺满不重复，
输入框本身改成百分之九十不透明的白，这样底图会隐隐透上来一点，
聚焦输入的时候再变回纯白，不影响打字。

本机验过。用 sharp 把图渲染出来自己看过一遍，
又拿一个半透明白输入框叠上去模拟真实布局看过一遍，
两侧留白确实填到了，四个角的图标都清楚，也不抢眼。
第一版左边的学士帽辨识度差，看图的人说像纸飞机，已经换成喇叭。
二十一条离线命令全绿，编译通过。
