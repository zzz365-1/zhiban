# 082 通知发布日期输入框统一中文表达

## 背景

第一张截图是新增通知弹窗里的发布日期输入框，空态显示成 yyyy/mm/日，
字母和汉字混在一处。这是浏览器对 type date 控件的本地化渲染，代码里并没有写这个字符串，
所以只能换掉控件本身，不能靠改 placeholder 解决。

## 本机已核验事实

发布日期在页面主文件里是字符串状态，当前格式是 2026-11-03 这种纯数字带短横线写法，
下游会交给 new Date 当换算基准，也会随通知对象存进本地存储。空值是空字符串。
日期解析模块导出的 parseUserDateInput 支持中文日期和标准写法，
返回对象里的 date 是真正的日期对象，normalized 是中文写法，不能直接当基准用。
留空行为是 Dec-061 的刻意设计，不许按今天猜。

## 验收要点

第一，空态不再出现任何拉丁字母，给中文示例。
第二，填中文日期或标准写法都能转成同一种纯数字带短横线的值。
第三，输入中间态不丢字不跳光标，格式不对给中文提醒。
第四，留空仍待确认，明确日期通知不受影响，保存刷新后仍认得。
第五，只输出改动片段，标明文件路径和要替换的原文。

## Prompt

```
新增通知弹窗里那个选填的通知发布日期，空着的时候框里显示的是几个英文字母加斜杠再加一个日字，半中半洋的，同学看着别扭，我们界面上别的标签都是中文。能不能把这个框换成普通文本输入，空着的时候给一句中文示例文字，框里不要再冒出英文字母。

填进去的值不能乱改。页面那边存的是年月日之间用短横线连起来的纯数字写法，解析的时候会拿它去换算下周三明天这种说法，所以不管我怎么填，最后交给页面的还得是同一种写法。我填中文日期也要能转成那种写法，填得不对就在框下面给一句中文提醒，别悄悄丢掉，也别让我打着字光标乱跳。留空的时候必须还是留空，不许拿今天的日期偷偷去算，原文里本来就写明日期的通知也不许受影响。保存到我的通知和刷新之后都还要认得这个值。

只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。改完我本机跑全量回归，还要在浏览器里真填一次，跑不过再回来找你。
```
