# 052a 第四轮之二 左侧导航与事项卡片组件

## 背景

设计规范已经落地，欢迎页也做完了。接下来做工作台。第一步先做两个纯展示组件，
它们不碰业务逻辑，只按传进来的数据显示，这样后面接工作台的时候风险最小。

## 几条硬约束

第一，只新建组件文件，不动现有文件。

第二，组件必须复用上一轮已经建好的那套通用组件和图标，不许自己另写一套按钮或状态标签。

第三，状态一律图标加文字，不能只靠颜色。

## Prompt

```
接着上一轮，现在开始做工作台。这一小步请先给我两个纯展示组件，它们不碰业务逻辑，只按传进来的数据显示，我后面再接到页面里。

老规矩再说一遍，这次不是重做，前面三轮的功能都还在。请你只新建文件，不要改动任何现有文件，也不要把已有文件整个重抄一遍。回复只给新文件的完整代码。

上一轮我们已经建好了一套通用组件和一个图标库，都放在组件目录下面的 ui 子目录里，这一轮请直接复用，不要再自己写一套按钮或者状态标签。

通用组件那个文件叫 ZbUI 点 js，里面导出了这些。Button 有 variant 取值 primary 或 secondary 或 ghost 或 danger，size 取值 sm 或 md，loading，disabled，icon，onClick，children。Chip 有 tone 取值 brand 或 neutral 或 warn 或 danger 或 success 或 accent，icon，children。Card 有 title，extra，children，onClick，selected。StatusPill 有 status 取值 待办理 或 已办理 或 无需办理 或 待确认 或 已过期 或 草稿 或 解析中 或 解析失败，size。SectionTitle 有 children，extra。EmptyState 有 icon，title，description，action。Modal 有 open，title，onClose，children，footer，width。

图标那个文件叫 Icons 点 js，里面导出了日历，时钟，地点，文件，对勾，感叹号，右箭头，加号，搜索，列表，首页，刷新，星星，叉，展开收起的上下右三个尖角，铅笔，转圈，空心圆，横线这些图标组件，名字分别是 IconCalendar，IconClock，IconPin，IconFile，IconCheck，IconAlert，IconArrowRight，IconPlus，IconSearch，IconList，IconHome，IconRefresh，IconStar，IconX，IconChevronDown，IconChevronRight，IconChevronUp，IconPencil，IconSpinner，IconCircle，IconMinus。每个都接收 size 属性。

这一轮统一的视觉规范再提醒一次，主色蓝色 2563EB，深蓝 0F172A，页面背景浅灰 F5F7FB，正文 0F172A，辅助文字 64748B，紫色 7C3AED 只在很少的点缀上用。卡片纯白底十二像素圆角一像素边框 边框色 E2E8F0，很轻的阴影。动效两百毫秒，并且要尊重系统的减少动态效果设置。

第一个组件，请新写一个左侧导航，放在组件目录里，文件名叫 SideNav 点 js。

它接收这几个属性。第一个叫 view，是当前视图的键，取值是 workbench 或 notices 或 calendar 或 changes。第二个叫 onViewChange，点导航项时回调，传新的视图键出去。第三个叫 counts，是一个对象，里面有这几个数字键，notices 表示通知总数，pending 表示有字段待确认的事项数，soon 表示三天内要办的事项数，todo 表示还没办的事项数，changes 表示有修改历史的通知条数。第四个叫 onCreate，点新增通知时回调。第五个叫 onBackWelcome，点返回欢迎页时回调。

版式请这样做。整个导航固定宽度二百四十八像素，整列占满高度，底色用深蓝 0F172A，文字是白色系，最外层不要有边框。

最上面是品牌区，上下留白二十像素左右，左右留白二十像素。一个三十八像素见方的圆角方块，底色用主色蓝，里面写知办两个字，白色加粗。右边一列，上面一行写知办两个字，十五像素加粗白色，下面一行写把校园通知变成清晰行动，十一像素，颜色用白色配百分之五十五透明度。

品牌区下面放一个新增通知的主按钮，宽度撑满，高度四十像素，主色实色，左边一个加号图标，文字是新增通知。这个按钮要有明显的悬停和按下效果，也要有键盘焦点环，焦点环在深底上请用白色的半透明环。

按钮下面是一条很淡的分割线，颜色用白色配百分之十透明度。

再下面是导航区，四个导航项竖着排，每项都是一个整行按钮，高度四十像素，圆角八像素，左边图标右边文字，图标和文字之间空十像素。四项分别是工作台配首页图标，我的通知配列表图标，日历配日历图标，变更记录配刷新图标。选中那一项底色用白色配百分之十二透明度，文字白色加粗，左边再加一条三像素的主色蓝竖条。没选中的文字用白色配百分之七十透明度，悬停时底色白色配百分之八透明度。

每个导航项的右边可以带一个小数字角标。我的通知那项显示 counts 里的 notices，日历那项不显示，变更记录那项显示 counts 里的 changes，工作台那项不显示。角标是个很小的圆角块，底色白色配百分之十六透明度，文字十一像素。数字为零的时候不许显示角标，也不许显示零。

导航区下面放一块统计区，先写一行很小的标题叫需要关注，颜色白色配百分之四十五透明度，十一像素。下面三行，每行左边一个小图标，中间文字，右边数字，高度二十八像素。三行分别是待确认配感叹号图标，即将截止配时钟图标，待办理配列表图标。数字用十六像素加粗白色。文字用十三像素，颜色白色配百分之七十五透明度。这三行也要能点，点了就调 onViewChange 传 workbench，并且在点击的时候额外回调一个 onFocusStat，传的字符串分别是 pending 或 soon 或 todo，如果调用方没传这个属性就什么都不做。

最底下靠底边放一个返回欢迎页的小按钮，文字十一像素，颜色白色配百分之五十透明度，左边一个右箭头图标旋转一百八十度的效果，悬停时变成白色。

整个导航在窄屏上不要求自适应，这一步只管桌面端。

第二个组件，请新写一个事项卡片，放在组件目录里，文件名叫 ItemCard 点 js。

先说传进来的数据长什么样，免得你去猜。这个卡片传进来的是一个事项事件对象，属性名叫 event，它上面有这些键。noticeId 是所属通知的编号，noticeTitle 是所属通知的标题，itemIndex 是这条事项在通知里的序号，name 是要做什么，ts 是毫秒时间戳，time 是格式化好的时间，location 是去哪，materials 是准备什么的数组，数组里每一项可能是字符串也可能是有 name 键的对象，progress 是办理状态，取值为待办理或已办理或无需办理，timeType 是时间类型，取值为 deadline 表示办理截止，start 表示活动开始时间。

卡片还要接收这几个属性。now 是当前时间毫秒数，selected 布尔表示是否被选中，onOpen 点了卡片主体时回调，onComplete 点了标为已办理时回调，onToggleMaterial 可选，点了某项材料前面的勾选框时回调，传两个参数，第一个是材料在数组里的下标，第二个是勾选之后的值。

卡片请这样显示。用通用组件库里那个 Card 包一层，selected 传进去。

第一行左边是一个状态标签，用 StatusPill 显示 event 的 progress。右边放一个时间类型的小标签，用 Chip，deadline 时文字写办理截止并用 brand 色，start 时文字写活动开始并用 accent 紫色。

第二行是卡片标题，也就是要做什么，十五像素加粗，正文色，最多显示两行，超出用省略号，不许换行把卡片撑变形。

第三行开始是四条信息，每条一行，左边一个十六像素的浅色图标，右边文字，图标和文字之间空八像素，字号十三像素，文字颜色用辅助文字色，其中数值部分用正文色加粗一点。四条分别是，何时配时钟图标显示几月几日空格小时两位冒号分钟两位，并且右边跟一个剩余时间的小标签，去哪配地点图标，准备什么配文件图标，来自配列表图标显示所属通知标题。剩余时间那个小标签请你自己按 now 和 ts 算，超过三天用 brand 色，三天内用 warn 色，一天内用 danger 色，已经过去用 neutral 色并且文字写已过期，文字内容分别是剩几天，剩几小时，不到一小时，已过期。

如果 location 是空字符串，去哪那一行整行不显示。如果 materials 是空数组，准备什么那一行整行不显示。请注意 materials 里每一项可能是字符串也可能是对象，取名字的时候两种情况都要处理，对象就读它的 name 键，不要直接把对象渲染到页面上。

材料那一行请做成能勾的样子。每一项材料前面一个小方框，已勾的显示对勾图标并且整行文字加删除线，没勾的空方框。点了就调 onToggleMaterial。如果调用方没传这个属性，就只显示文字不显示方框。

卡片最下面一行放两个操作。左边一个描边小按钮，文字是查看详情，点了调 onOpen。右边一个按钮，如果当前是已办理就显示撤销，用 ghost 样式，点了调 onComplete 传字符串已办理之外的上一个状态也就是待办理，请你用一个参数把状态传出来，签名就定成 onComplete 传一个字符串。如果当前不是已办理就显示标为已办理，用 primary 小按钮，点了调 onComplete 传字符串已办理。已办理的卡片整体文字请稍微淡一点。

两个操作按钮都要能键盘聚焦，都要有悬停和按下效果。整张卡片点主体区域也能触发 onOpen，并且能键盘聚焦，回车和空格都能触发。

动效方面，卡片请加一个很短的入场效果，请直接用样式文件里已经定义好的入场动画类名，不要自己再写关键帧。悬停时边框变浅蓝阴影稍明显。

请你只输出这两个文件的完整代码，不要解释，不要改动任何现有文件。
```
