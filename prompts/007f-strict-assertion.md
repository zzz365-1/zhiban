## 为什么还有这一步

007e 交付后表面 18 PASS / 0 FAIL，且第 3、16 条实际值确实变成了空。
本机复核确认修复是**真实的**，路径如下：

```
本地规则修正 → 「本月25日」不再被截断成「本月」
isFuzzyDate 覆盖「本月25日」→ 判定为模糊 → 触发模型
模型返回 null → mergeAIResult 对模糊源不再回退原文 → 最终为空
```

**但 007e 里「不许藏失败」这一条并没有真正落地。**

`scripts/test-relative-dates.mjs` 的判定仍是：

```js
const ok = actualNorm === expectedNorm;
```

`normalizeDate` 对任何不可解析字符串返回 null，与期望的 null 相等 ⇒ 判为 PASS。
本机实测，期望为空、实际分别为「本月」「本周」「在校生」「行政楼」「明天xyz」，
**全部判 PASS**。

即：安全网没有装上，只是今天上游恰好干净，所以没触发。
