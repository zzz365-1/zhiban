# 081 事项清单移出字段栅格并统一标签写法

## 背景

截图里解析结果滚到底部时，分类那一格在左半列，事项清单整块被塞进右半列，
左侧空一大片，事项卡片里的系统建议文字折得很难看。
原因是事项清单区块写在字段两列栅格的里面，被当成了一格，而不是栅格下方的独立整行。

同学还要求检查并统一表示方式的文字形式，同一类标签里不许中文和字母混用。
扫描到摘要和分类旁边各挂一个两字母小标记，页面主文件里另有一处来源标签是字母加中文。

## 本机已核验事实

解析结果组件的字段栅格从第 234 行开始，事项清单区块从第 371 行开始且位于栅格内部。
第 270 到 274 行是那个两字母小标记，只在字段带 ai 标记时渲染。
页面主文件的来源标签函数里 mixed 分支返回字母加中文辅助，其余三个分支都是纯中文。

## 验收要点

第一，事项清单整宽，分类仍留在字段区，上面字段下面事项层级清楚。
第二，两字母小标记换成中文说法，其余中文标签一字不动。
第三，来源标签 mixed 分支换成纯中文，其余三个分支一字不动。
第四，间距收紧但内容不截断，字段与事项都完整保留。
第五，只输出改动片段，标明文件路径和要替换的原文。

## Prompt

```
解析结果往下拉到底还有一处问题。分类那一格在左边，事项清单整块被挤在右边半列里，左边空掉一大片，事项卡片窄得连系统建议那几行字都折得很难看。我看了组件，事项清单那一块好像被放进了字段用的两列栅格里面，被当成了一格。能不能把它挪到字段栅格外面，自己占满整行，分类那一格还是留在字段区里，这样上面是字段下面是事项，一眼分得清。

还有标签写法不统一。摘要和分类旁边各挂了一个两个字母的小标记，跟旁边的中文混在一起，页面主文件里还有一处来源标签是字母加中文辅助。能不能把这些换成中文说法，同一类标签要么全是中文，别一半中文一半字母，来源标签其余几个分支一个字都不要动，别的中文标签也一个字都不要动。

顺带把间距理一理。字段标签和值框现在贴得有点松，事项清单的标题跟上面字段区也分不出层级，改完要紧凑但不挤，长文字要完整显示不许截断，所有字段和事项都要还在。

只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。改完我本机跑全量回归，跑不过再回来找你。
```
