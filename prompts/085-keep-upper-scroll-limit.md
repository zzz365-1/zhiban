# 085 保留上区高度上限与外层滚动，补回卡片层级

## 背景

084 让原文框按内容撑高，短通知看全了，但同一版把上区的最大高度四成
与外层滚动容器一起删了。二十一行长通知会把上区撑到五百多像素，
在 720 高的窗口里把下方解析结果顶到只剩一条缝，违反验收要点 B3。
本机侧只落位了 084 的自适应高度与弹窗输入框两处，上区结构仍是 080 那版。

## 本机已核验事实

当前上区是带最大高度四成和外层滚动容器的结构，textarea 自适应高度已生效，
但还缺卡片外壳和标题分隔线，textarea 类名里也没有配合自适应的溢出处理。
字段高亮定位依赖编号，不能动。弹窗输入框已按 084 改好，本轮不碰。

## 验收要点

第一，短原文整段可见且上区贴合内容，无大片留白。
第二，长原文由整个上区滚动，上区最多四成高，下区始终占得住。
第三，原文框自身不出滚动条，编号与高亮不变。
第四，恢复卡片外壳与标题分隔线，层级清楚，间距紧凑。
第五，只输出改动片段。

## Prompt

```
上一版我把截图发过去之后，你给的原文卡片那版我照着试了一下，短通知是能看全了，可是二十行的长通知把上半块撑得很高，下面解析结果只剩一条缝，差不多被顶出屏幕了。我看了下，那一版把上区原来的最大高度四成和外层那个滚动容器一起删掉了，长文本就没有地方滚了。

能不能把这两样留回来。上区还是最多占四成，超了由整个上区自己滚，原文框自己不要滚。卡片外壳和标题栏那条分隔线保留，短通知还是跟着内容收，不留白。原文框按内容撑高的那段保留，别删，编号也别动，高亮定位还要用。

另外弹窗那个原文框我已经按上一版改了，不用再动。只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。改完我两种分辨率重新截图，短通知和长通知都看，跑不过再回来找你。
```
