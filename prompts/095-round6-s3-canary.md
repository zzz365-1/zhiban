# 095 第六轮清脏标记断言承重修正

## 背景

六处注入坏实现里，五处按预期报红，只有删掉确认切分后的清脏标记那一处仍是全绿。

## 本机已核验事实

断言截取确认切分函数片段时，用换行加两个空格加 function 找下一个函数起点，
但紧随其后的函数是 async function，匹配不到，于是片段把后面的函数也包了进来。
后面的作为单条解析函数里同样有一行清脏标记，被拿去顶了数，所以删掉目标行也不报红。

## 验收要点

第一，片段严格止于下一个函数声明，async 开头也要认。
第二，断言限定为落批量结果之后紧跟的那一行清脏标记，删掉必须报红。
第三，只给这一对替换片段，不动其他断言和生产代码。

## Prompt

```
我按规矩把改过的地方一处一处改坏试了一遍，六处里五处都按预期报红了，只有一处没反应。就是我把确认切分之后清掉待重新解析标记那一行删掉，检查还是全绿。我看了一下，检查里截取确认切分函数那一段的时候，好像把后面的函数也一起算进去了，后面别的地方也有一行一样的清标记，于是它拿那一行顶了数。能不能把这段改成只盯确认切分函数里落结果之后紧接着的那一行，删掉就一定要报红。只给我这一处要改的片段，别的断言别动。
```
