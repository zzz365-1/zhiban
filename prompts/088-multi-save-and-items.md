# 088 多通知保存被卡住与批量缺事项

## 背景

同学想演示一次粘贴多条通知一起解析保存，结果确认切分之后保存按钮一直是灰的，
顶部还挂着内容已修改待重新解析。绕开按钮把结果存进去，详情页的事项清单又是空的。

## 本机已核验事实

输入文本时 dirty 被置为真，全文件只有选中通知 单条解析 作为单条解析 单条保存四处把它清掉，
多通知从确认切分到生成批量结果这一路没有清。保存按钮的可用条件以 dirty 为第一道闸，
保存函数开头也先判 dirty 再分流到多通知，所以批量保存永远走不到。
批量结果每条只放解析结果，没有像单条那样补事项，落盘的通知顶层也没有事项字段。
结果面板标题截四十字，保存后的列表标题截三十字，同一条通知前后标题会变。

## 验收要点

第一，确认切分并解析完成后保存按钮可点，顶部不再挂待重新解析。
第二，切分弹窗取消时不要清 dirty。
第三，批量每条解析结果都带事项，落盘通知顶层也有事项。
第四，结果面板与列表标题口径统一。
第五，单条模式的 dirty 逻辑一行不改，只输出改动片段。

## Prompt

```
我今天想给老师演示一次粘贴好几条通知一起解析，结果卡住了。我切到多通知，把两条通知中间空一行粘进去，点开始解析，弹窗让我确认怎么切分，我确认之后每一条都解析出来了，结果面板也写着保存两条到我的通知，可这个按钮是灰的，怎么点都没反应，顶部还一直挂着内容已修改待重新解析。我退回单条模式试同一段内容，保存按钮是好的。后来我想办法绕过按钮把结果存进去看了一眼，打开通知详情，事项清单里写着这条通知里没有拆出具体事项，别的通知都有两条事项。我有点慌，是不是我哪一步点错了，还是程序哪儿没接上。能不能帮我看一下多通知这条路从确认切分到保存中间少了什么，顺便让存下来的通知也有事项，只改这几处就好，单条模式千万别动坏。
```
