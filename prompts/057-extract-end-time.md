# 057 第五轮之一 抽取活动的结束时间

## 背景

这一轮要做日程冲突提醒。要判断两项活动到底重不重叠，光有一个开始时间不够，
必须知道各自什么时候结束。现在事项上只有一个时间点，缺结束时间。
所以第一步是把结束时间从原文里抽出来。

## 几条硬约束

第一，只新增，不许动现有那个抽时间的函数，也不许改现有返回值的含义，
不然之前几百条用例会跟着动。

第二，抽不到必须返回空，绝不猜时长。原文没写结束时间就是没写，
后面界面会提示信息不足，不靠假设补齐。

第三，新增的抽取路径只能放在最后兜底，前面能抽到的都不许抢。

第四，正则里表示数字一律写成零到九的字符类，不要写成反斜杠加字母那种写法。
换行一律写成回车可选加换行的写法。

## Prompt

```
前一版跑通了，现在要给它加一个新能力，你要做的是加东西，不是重做，请不要把已有文件整个重抄一遍，只输出改动的那几段，标明落在哪几行附近。

我想做的这件事是这样，我要判断两个活动的时间有没有重叠，比如答辩是十四点到十六点，讲座是十五点到十七点，那它们重叠了一小时。但要判断这个，我得先知道每个活动什么时候结束，现在我的每个事项上只有一个开始时间，没有结束时间，所以第一步请你帮我从原文里把结束时间抽出来。

先说清楚现在的代码长什么样。抽取那个文件里已经有一个函数叫 extractTime，它接收原文和一个日期候选，返回一个小时两位数字英文冒号两位分钟的字符串，抽不到返回空。它先在原文里切出日期所在的那一小句，只在那句里找，然后从三种写法里依次匹配，第一种是带上午下午这类时段词的，第二种是纯英文冒号或中文冒号隔开的，第三种是带点字或时字的。还有一个函数叫 extractEndTime 是不存在的，我要你新建的。文件末尾有一个导出的总入口函数，它返回一个对象，里面有 deadline，eventDate，eventTime，time，location，materials，audience，category 这些键，其中 time 和 eventTime 都是调上面那个 extractTime 得到的。请你在这个文件里新建一个导出函数，名字就叫 extractTimeRangeEnd，它接收两个参数，第一个是原文整串，第二个是日期候选，和 extractTime 的第二个参数一样，找不到就返回空。

它的做法请你这样写。第一步，用和 extractTime 一样的办法把范围切出来，也就是只在那日期所在的那一小句里找，句子太长就退化成按字数截断，这段逻辑你可以自己再写一遍小的辅助函数，不要去改原来的那个。第二步，在这个范围里从最左边开始找第一个时间的写法，三种写法都要认，带时段词的，英文或中文冒号隔开的，带点字或时字的，找到之后记下它的结束位置，并且把它换算成小时和分钟两个数字。第三步，从这个结束位置开始往后看，先允许有空格，然后必须是一个连接符，连接符只认这几种，英文短横线，中文那种一字线，中文那种长破折号，波浪号，全角波浪号，中文的到字，中文的至字。连接符后面允许有空格，然后必须紧跟着一个时间的写法，同样是那三种写法都要认。这里有个硬性要求，连接符后面如果跟的不是时间，比如跟的是日期或者地名，那这一次就算没找到，直接返回空，不许凑数。比如八点到校医院三楼体检中心这种，到字后面不是时间，就不能把校医院当成结束时间。再比如十一月五日下午五点前报送，五点后面根本没连接符，也返回空。

第四步是时段词的处理，这里有个真实的坑。原文经常写成下午两点到四点，开始那头写了下午，结束那头没写。这种情况下结束那头要沿用开始那头的时段词，也就是四点要算成十六点，不能算成四点在凌晨。反过来，如果开始那头也没写时段词，那两头都按字面算，不要凭空加十二小时。如果结束那头自己写了时段词，那就以它自己写的为准，不要继承。需要加十二小时的时段词是下午，晚上，傍晚，晚，中午这五个，其中中午比较特殊，它只在小时数小于十二的时候才加，这个你看着办，跟现有那个函数保持一致就行。还有凌晨这个词，如果小时正好是十二就当成零。分钟那块也是跟现有一致，写了数字分就按数字，写了半就是三十分，都没写就是零分。

第五步是最后一道校验，把开始和结束都换算成分钟数比一下，结束必须严格大于开始，等于或者小于都返回空。这样能挡住两种错，一种是原文里其实不是区间被误读成区间，另一种是跨午夜的那种我暂时不想处理，先返回空，后面界面会提示信息不足。

第六步，请把抽出来的结果接到总入口上。在总入口那个函数里，给返回对象加两个新键，一个叫 endTime，一个叫 eventEndTime。endTime 是截止那条线上的结束时间，eventEndTime 是活动那条线上的结束时间，都是先判断对应的开始时间是不是空，空的话就填空，不空才调你新建的那个函数。这两个键请放在返回对象已有那几个时间键的后面，不要插到最开头。

最后一件事，这一轮先不要碰冲突判断本身，也不要改界面，也不要去动切事项那个文件，我这一步只要抽取这一层能拿到结束时间。改完我本机跑，跑不过再回来找你。
```
