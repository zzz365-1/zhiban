# 065 第一轮自检 材料抽取把一整段话当材料

## 背景

第一轮自检时，用一批没有参与过开发的新通知跑生产模块，
发现材料字段会把一整段话当成要交的材料，界面上会直接显示出来，很丢人。

第一条原文是，
请各实验室对照检查表完成自查，发现问题及时整改。
抽出来的材料是，请各实验室对照检查表。
这显然不是一份要交的材料，它是一句祈使句的前半段。

第二条原文是，
毕业生须于11月8日至11月10日每日9点00到16点00携带本人身份证和学生证到体育馆一层完成采集。
抽出来的材料是，本人身份证，还有学生证到体育馆一层完成采集。
第二个把地点和动作也一起吞进去了，应该只是学生证。

## 本机已核验事实

材料抽取在抽取模块里，返回的是一个字符串数组。
上面两条的实际返回值已经在本机跑过，就是上面写的那样。

## 验收要点

第一，第一条的材料应该是空数组，不要硬凑。

第二，第二条的材料应该是身份证和学生证这两样，不能带地点和动作。

第三，原来能正确抽出的材料一条都不能丢，现在套件里有一条专门盯住
班会记录表不能被当成材料，还有一条盯住讲座介绍简历不能被当成需交简历。

第四，宁可抽不出来也不要抽错，抽错会让用户照着错的清单准备。

## Prompt

```
我发现我的程序还有个毛病，材料字段会把一整段话当成要交的材料，界面上直接显示出来，很丢人。

我试了两条。第一条原文是，请各实验室对照检查表完成自查，发现问题及时整改。抽出来的材料是，请各实验室对照检查表。这显然不是一份要交的材料，它是一句祈使句的前半段。第二条原文是，毕业生须于11月8日至11月10日每日9点00到16点00携带本人身份证和学生证到体育馆一层完成采集。抽出来的材料是，本人身份证，还有学生证到体育馆一层完成采集。第二个把地点和动作也一起吞进去了，应该只是学生证。

能不能帮我改一下材料抽取这一段。我想要的效果是，第一条的材料应该是空的，不要硬凑，第二条的材料应该是身份证和学生证这两样，不要带地点和动作。

我猜问题出在材料短语的结尾没有切干净，遇到后面跟着地点或者动作就一直往后吃。你看看是不是这个原因，或者有别的更稳的切法也行。

有几条请你严格守住。第一，宁可抽不出来也不要抽错，抽错会让用户照着错的清单去准备东西，比空着更糟。第二，原来能正确抽出来的材料一条都不能丢，我现在有一批用例在盯这个，其中一条是班会记录表不能被当成材料，另一条是讲座介绍简历不能被当成需交的简历。第三，正则请一律用字符类，不要出现反斜杠加数字。第四，只改材料抽取这一段，别的字段不要动。

请只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。改完我本机跑全量回归，跑不过再回来找你。
```
