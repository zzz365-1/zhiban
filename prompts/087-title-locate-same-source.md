# 087 标题与非原文字段的定位误报

## 背景

同学发来一张截图，说标题没被识别。截图里通知第一行是第十五届校园歌手大赛报名通知，
解析结果的标题一行也显示这句话，点这个值之后下面却冒出红字，说原文里没找到这段内容请自行核对。

## 本机已核验事实

生产模块 extractNotice 返回的字段里没有 title，界面标题是 getNoticeTitle 从通知对象的标题
或者原文首行兜底显示出来的。点击字段走 fieldLocate 的 findSpan，取的是 analysis.title，
这个值一直是空，所以必然报找不到。摘要和分类本来就不是从原文抄出来的值，
换算过的时间和日期也与原文写法不同，它们同样被做出处定位，报的是同一句红字。
另外暂无摘要这个空态文案没有被当成空值，点下去也会报错。

## 验收要点

第一，标题点击后要真的选中原文里对应的那段文字，不再出现红字。
第二，摘要和分类点击时不给红字，也不触发高亮。
第三，暂无摘要 未识别 未分类 都按空态处理。
第四，换算过的日期和时间要给出与换算相符的说明，不要一律说成原文里没找到。
第五，其余字段的定位行为不变，只输出改动片段。

## Prompt

```
我在试自己做的校园通知助手，碰到一个我怎么也想不明白的现象。我粘贴了一条通知，第一行是第十五届校园歌手大赛报名通知，解析结果里标题那一行也确实显示这句话，可是我点了一下标题，想让它跳回原文对应的位置，下面立刻冒出一行红字，说原文里没找到这段内容请自行核对。我对照原文第一行看了好几遍，明明是一模一样的字。我又点了摘要和分类，摘要那里写的是暂无摘要，分类写的是活动，点下去也照样冒这行红字。还有一条通知原文写下午5点，界面显示十七点，点具体时间又冒同一句红字。我现在分不清这些值到底是没识别出来，还是只是没法跳回原文，演示的时候挺尴尬的。我想让标题这种确实从原文来的值点了以后真的能选中原文，摘要和分类这种本来就不是从原文抄出来的值不要吓我说没找到，换算过的时间或者日期如果和原文写法不一样，给一句说得通的解释就好，别一律报同一句红字。我不知道该从哪儿下手，能不能帮我看看这几处是怎么走的，只给我需要改的那几段代码，别顺手把别的功能删了。
```
