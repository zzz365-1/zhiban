# 007 地点抽取修正

归档时间：2026-10-31
状态：待发给 DeepSeek

## 缺陷描述

`app/lib/extractNotice.js` 的 `trimLocation` 采用「从片段起点截到最后一个关键词」的写法，
导致介词后的整段动词短语被当成地名返回。

实测 18 条语料，**17 条正确，1 条严重错误**——N4「校园安全隐患排查」返回 `全校范围内开展宿舍`。

## 为什么这条错误比表面严重

`aiExtract.js` 的 `isRuleResultGood` 判据是 deadline 与 location 同时非空。
N4 的假地点非空，导致该条被判定「本地规则已够好」，**模型全程未被调用**，
于是 deadline 也失去了被修正的机会。一处错误连带污染两个字段，且界面无任何异常显示。

## 修复方向

1. 后置校验：命中片段若含 开展 / 举行 / 举办 / 排查 / 进行 等动作词，直接返回 null，宁缺勿滥。
2. 边界回溯：从命中的地点关键词向左扩，遇到介词或动词即停，保留前置修饰语（修复「三楼自习室」丢楼层）。
3. 必须附带可在终端执行的验证脚本，覆盖全部 18 条语料。
