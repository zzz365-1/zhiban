# 080 通知详情改回上下分区

## 背景

同学发来两张截图。通知原文和解析结果现在是一左一右排的，原文那栏占四成四，
文字只有四行，下面空掉一大片。解析结果被挤在右半边，自己还带一根滚动条。
项目很早就定过方案二，原文在上结果在下同屏对照，后来这层被第四轮的详情两栏覆盖掉了。

## 本机已核验事实

详情容器组件主体是一个横向 flex，左栏是原文，宽度按是否折叠切成两种，
右栏是详情面板。原文输入框固定了四百像素的最小高度，这是大片留白的直接来源。
折叠态里用了竖排文字，改成上下之后竖排文字会变得很怪，要一并处理。
原文输入框的编号被字段高亮定位功能依赖，不能动。独立查看原文的弹窗与本轮无关。

## 验收要点

第一，原文短时上方跟着内容收，下方占满剩余高度，中间没有大片空白。
第二，原文长时上方自己滚，不把下方顶出屏幕，整页不出现第二根滚动条。
第三，结果内容多时下方自己滚，顶部状态栏和按钮始终可见。
第四，折叠功能保留，折叠后是一条横向细条，展开恢复。
第五，只输出改动片段，标明文件路径和要替换的原文。

## Prompt

```
我把页面截了张图给同学看，同学说通知原文和解析结果现在是一左一右排的，这跟我们很早就定下的上下分区不一样，要改回去。左边原文那块其实只有四行字，下面却空了很大一片，右边解析结果被挤在半边，自己还得带一根滚动条，看着很散。能不能让原文在上面，解析结果在下面占满整个宽度。

我特别在意几件事。第一，原文短的时候上面那一块要跟着内容收，不要固定撑得很高，下面结果区要占满剩下的地方，中间别再留一大片白。第二，原文长的时候上面那一块自己能滚，不能把下面整块顶出屏幕，也不能让整个页面跟着一起滚。第三，解析结果内容多的时候下面那一块自己能滚，顶部的状态栏和那些按钮要一直看得见。第四，折叠原文那个功能还要能用，折叠之后应该是一条横着的细条，不要再出现竖着写的字。第五，独立查看原文的弹窗别动，原文输入框的编号别动，点解析结果里的字段跳回原文高亮的那个功能也别动，之前就是靠那个编号定位的。

只给我需要改的那几段代码，标明文件路径和要替换的原文，不要输出整份文件。改完我本机跑全量回归，还要在两种分辨率下截图看，跑不过再回来找你。
```
