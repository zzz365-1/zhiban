# 022 界面布局改上下结构（方案二）

## 背景

老师拍板要改的布局。当前是三栏 `260px | 1fr | 280px`，宽屏下中间大片空白只放一个
输入框，右栏 280px 却要塞八个字段。中间空白与右栏拥挤是同一个原因：宽度分配失衡。

方案二形态：上半部输入区，下半部结果区用**两列栅格**排布字段。

两个必须写进提示词的点：
1. 不能把 280px 那根竖条原样搬到下面（下方仍单列堆叠等于没兑现收益）
2. 015 的空态现在占满中间 `flex-1`，改上下后要只占上半部分，否则结果区没位置

## Prompt

```
我想请你帮我改一下页面的布局，这个改动可能比较大，我先说清楚现在是什么样和想改成什么样。

现在的布局是三栏，左边一列大概二百六十像素放通知列表，中间放输入框，右边一列大概二百八十像素放抽出来的结果。问题是在宽屏上中间那一列特别宽，可是里面只放了一个输入框，下面一大片都是空的。右边那一列只有二百八十像素，却要塞进去八个字段，其中材料那个是好几个值，摘要是一整句话，挤得很。我自己看下来觉得这两个问题是同一个原因，就是宽度分配不合理，右边不够不是因为内容多，是因为给它的宽度太少了。

我想改成上下结构。上面半部分是输入区，保持现在这些功能不要丢，宽度适当收一收。下面半部分是结果区，里面那些字段用两列的格子来排，材料一格可以单独占一列或者横向铺开。

有一个坑我想特别提醒你。不能把右边那根二百八十像素的竖条原样搬到下面去。如果下面结果区还是单列一个一个堆下来，那宽度的好处就等于没有兑现，只是把拥挤从右边挪到了下面。要做就做彻底一点。

还有一个地方可能会打架。现在有一个空状态的引导，就是还没输入内容的时候显示的那些示例和提示，它现在是把中间那一整块都占满了。等改成上下结构之后，结果区在下面，如果空状态还是占满整块，下面就没地方了。我想的办法是让空状态只占上半部分，或者在没有结果的时候直接把结果区折叠起来。具体哪种你看着办，但是这个一定要处理，不然改完界面会出问题。

还有几件老规矩麻烦你一起遵守。第一，这个项目没有配置路径别名，写代码不要用那个艾特符号开头的路径，一律用点杠开头的相对路径。之前用了艾特开头的路径，程序直接报找不到模块，网页打不开。第二，不要另外新建一个名字差不多的模块。第三，写正则一律用字符类，不要出现反斜杠加数字。第四，不要加新的依赖包。第五，那个存各种命令的文件里原有的命令一条都不能删，特别是那条查密钥的，改完请把所有命令都跑一遍，把结果一起给我。

改完之后我这边会在浏览器里看效果，所以麻烦你把改动说清楚一点，哪个文件改了哪几行，让我知道去哪里找。

还有一件很重要的事，请你回复的时候不要把文件整个重新输出一遍，那几个文件都很长，你全部打出来我会看不过来，而且容易把本来没问题的地方也改坏。你只要告诉我改动落在哪几行，把改之前和改之后的那几行分别写出来，我自己去替换。如果改动分散在好几处，就一处一处分开说清楚，每处都标明大概在第几行。

另外说明一下，我是新开的一个对话，之前聊过什么你这边看不到了，所以你只能根据我这次发给你的这些文件来判断，不要假设你还记得之前我们说过什么。如果我给的信息不够你判断，你直接问我，我去补。

我不太懂页面布局怎么排，如果哪里说得不对，你按你的判断来就好。
```
