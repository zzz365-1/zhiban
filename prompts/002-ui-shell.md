## Prompt 正文（可直接整段复制）

```
上次那个骨架跑起来了，浏览器里已经能看到"知办"两个字，谢谢你！现在我们把它变成真正的界面。

我想做的是这样一个三栏的样子：最左边一列是已经导入的通知列表，每条显示标题和来源，点一下能选中，
选中了右边才显示它的内容；中间是最大的一块，放一个能粘贴通知原文的文本框，下面一个"解析"按钮；
最右边显示这条通知的解析结果，比如截止日期、地点、要提交的材料、需要做什么，这些栏目先占个位。

有几点我提前说清楚，免得你做多了：这一步先不要接 AI，也不用真的去分析通知文本。通知列表里先用几条
假数据写死在代码里就行，内容就按校园通知来，像"关于开展2026年秋季学期教材征订工作的通知""本学期
体测补测安排"这种，我主要是想先看到整个界面长什么样。点那个"解析"按钮暂时没反应也行，或者给个
提示框都可以，真正的分析逻辑我们下一步再做。

另外我在想一件事：现在整个页面就写在 page.js 里，如果所有东西都堆在一起会不会太乱、以后不好改？
这块你比我懂，你觉得要不要拆成几个组件？按你的判断来，如果拆的话告诉我每个文件叫什么名字、
放在哪个目录下。

样式还是用 Tailwind。整体想要干净一点，有卡片、有阴影那种层次感，看起来像个正经的办公工具，
别太花哨。颜色我想走偏冷静的蓝色调。三栏的宽度上，左边那列窄一些，右边次之，中间最宽，因为粘贴
通知需要地方。还有一个小要求，文本框最好能自动长高，粘贴很长一段通知的时候不要挤成一行。

麻烦还是把每个文件的完整代码都给我，我会在 VS Code 里一个一个新建文件粘进去。改完之后告诉我
怎么看到效果——我这边 npm run dev 可能还开着，是不是直接刷新浏览器就行？如果不行该怎么做也说一声。
```

## 使用说明（给搬运者）

1. 整段复制上面代码块内的内容，粘贴进 DeepSeek；
2. 它返回的文件逐个在 VS Code 中新建（路径含 `/` 的输入框会自动建目录）；
3. 全部 `Ctrl + S` 保存后，**回到浏览器按 F5 刷新**即可看到界面（Next.js 热更新，无需重启服务）；
4. 若刷新无变化，回到终端按 `Ctrl + C` 停掉，再敲 `npm run dev` 重启。
