# 067 第三轮自检 补充通知里晚7点算成早上七点，取消项重复

## 背景

第三轮自检时用新的补充通知跑生产模块，发现两个毛病。

第一条原文是，
关于取消原定11月28日决赛的通知，换行，
因故取消原定11月28日晚7点的决赛，后续安排另行通知。
抽出来的变更项是，取消，取消，还有时间等于07点00。
晚7点应该是十九点，算成早上七点差了十二个小时。
这不是补充通知专用写法，校园通知里晚7点极其常见。

第二条原文是，
延期通知，换行，原定11月20日截止的报名延期至11月30日17点00，其余要求不变。
这条能正确认出是补充通知，变更项是日期和时间，没问题。

同一条取消通知里取消项出现了两次，一次来自标题里的取消二字，
一次来自正文。最终对比只显示一行，暂时没造成错误，
但变更项里带着重复项是脏数据，将来加了别的处理容易出问题。

## 本机已核验事实

补充通知抽取模块里，时间候选是一个正则，
它的时段词那一组是上午，下午，中午，晚上，晚间，凌晨，早上，傍晚，
里面没有单独的晚字。所以晚7点匹配不到时段词，七点就被当成早上。
同样的坑在另一个抽取模块里早就踩过一次，那边已经补上晚字了，这边漏了。

## 验收要点

第一，晚7点要算成十九点，不能是七点。

第二，晚上七点，晚七点半，下午两点这些说法都不能坏。

第三，同一条通知里的取消项只保留一个。

第四，原来二十六条补充通知用例一条都不能挂。

## Prompt

