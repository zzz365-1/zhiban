# 038 讲座里提到的简历不能当成要交的材料，行政楼也不能当行政类的证据

## 背景

同学试用时抓到两类误报。一类是把讲座内容当成了要交的材料，讲座介绍简历制作与面试技巧，材料栏填了简历，其实这场讲座什么都不用交。另一类是把场地名当成了材料或分类证据，图南楼报告厅里的报告被当成材料，行政楼里的行政被当成行政类通知的证据。

同时还有个反向缺口，体温监测表这种词表里没有的说法抽不出来，材料栏是空的。

## 几条硬约束

第一，误报和漏报要一起治，只堵一边会按下葫芦浮起瓢。

第二，真有交这个动作时还得能抽到，将简历交至就业指导中心这里简历是真要交的。

第三，材料词前面贴着纸质电子这类限定词时要一起带上，纸质申请表不能只给申请表。

第四，分类是推断出来的，不是从原文抄来的值，所以要允许它在拿不准的时候不给。

## Prompt

```
上次那个依据反查的模块我按你说的改好了，十分感谢。这一轮我拿十条真实通知给同学试，同学抓到两类毛病，我把原文抄下来了，想请你帮我一起改。

第一类是把讲座讲的内容当成了要交的材料。有一条就业指导讲座，原文里写着讲座介绍简历制作与面试技巧欢迎参加，我们的程序在材料那一栏给我填了简历。可是这场讲座什么都不用交，它只是讲怎么做简历。同学说这样很容易误导人，一看要交简历还以为要投简历。

同一类还有场地名被当成材料。有一条写在图南楼报告厅举办，报告两个字被收进材料里了。还有一条写在会议室开会，也被收了。

第二类更隐蔽。有一条只是通知班长去行政楼A302会议室，程序给判成了行政类。可是这里的行政说的是那栋楼的名字，不是这条通知的性质。类似的还有大学生活动中心，这里的活动说的是场地。会议室里的会议说的是房间。

另外还有个反过来的缺口。有一条通知要各班交体温监测表，我们材料栏是空的，认不出来。报名表和申请表能认，体温监测表就认不出，我猜是因为我们的词表是一个一个词列出来的，表这个字结尾的说法太多了列不全。

我想请你帮我改这两处，一处是材料，一处是分类，都在抽取那个模块里。

材料这边我有几个想法，你看行不行。第一，凡是表或者单或者册结尾的名词都当材料候选，不要一个一个列词，体温监测表这种就能认出来了。第二，纸质和电子和手写这类限定词贴在前面的时候要一起带上，纸质申请表不能只给申请表两个字。第三，材料词后面紧跟着厅或者馆或者楼或者室或者中心或者处或者部或者会堂这种字，说明它是地名的一部分，不是要交的东西，要挡掉。第四，介绍讲解讲授分享涵盖涉及主题内容这类词后面紧跟的词，说的是讲座讲什么，不是要交什么，也要挡掉。第五，但是挡的时候要留个口子，如果这一句里真的有交或者提交或者报送这种动作，那就以动作为准，还是收进来，因为动作比语境可靠。

分类这边我想的比较简单。给每个分类词配一张小表，写清楚它后面紧跟哪些字的时候不算证据。比如行政后面跟楼或者馆或者处或者大厅或者中心或者办公室或者会议室就不算，活动后面跟中心或者室或者厅就不算，会议后面跟室或者厅或者楼或者中心或者场就不算。判断的时候不能只看这个词在不在原文里，要往后看几个字。

有两条老规矩请一起守住。第一条是拿不准就不给，宁可让那一栏空着也不要给一个像答案的假值，这是我们这个项目一直的原则。第二条是正则全部用字符类写法，不要用反斜杠加数字那种。

下面这些是我一条一条试出来的结果，请你照着核对，不要自己另算。

讲座定于11月14日下午两点半在图南楼报告厅举办，讲座介绍简历制作与面试技巧，欢迎参加。材料那一栏应该是空的，一个都没有。

学术报告会将于11月10日举行，请携带学生证。材料只有学生证，报告会这三个字不能进去。

请于11月9日前将简历交至就业指导中心。材料里要有简历，这一条是真要交的，不能挡。

请各班于明天下午5点前将体温监测表交至学院学工办B203。材料里要有体温监测表。

请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室。材料是纸质申请表，纸质两个字要带上，不能只给申请表。

请各班班长11月8日晚7点到行政楼A302会议室。分类是空，不要判成行政类。

11月8日晚7点在第三会议室集合。分类也是空。

关于2026年国家助学金评审工作安排的通知。分类是行政，这一条是真的，不能因为上面那些改动被误伤。

第十五届校园歌手大赛报名通知。分类是活动，也不能被误伤。

关于冬季学生宿舍安全卫生检查的通知。分类是后勤，同样不能被误伤。

麻烦你只告诉我改哪几处和改成什么，不要给我整个文件的完整实现，之前有一次你给了完整实现，把已经做好的功能覆盖掉了一大片。另外这次请只动材料和分类这两处，日期时间和地点和面向对象都不要碰。
```

## 验证

十二条期望全部达标。这一轮往返了三回。

第一回给的版本挡不住学术报告会，因为材料词后缀表里只有厅馆楼室中心处部会堂，没有单独的会字。同时收表字结尾的词时一路往前吃，体温监测表变成了下午5点前将体温监测表。

第二回补上截断逻辑和会字，又冒出把纸质和电子无脑加在前面的新问题，根因是我落位时漏抄了它的一个保护条件，补回后正常。

第三回是全量回归抓出来的，请携带申请表1本被吃成请携带申请表，截断字表补上带送交这些动作字后修好，同时确认报名表不会被截成名表。

跑完材料日期二十四条全过，地点六十九条、分类五十九条、出处核对四十一条、相对日期二百三十四条一条没坏。
