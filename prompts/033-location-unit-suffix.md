# 033 地点补行政单位名，处科室办部学院这类整类漏掉

## 背景

无密钥纯本地规则下，一百条真实通知跑完，地点有二十九条是空的。我把这些空的原文全列出来看了一遍，规律很整齐，几乎全是行政单位名做地点，比如教务处考务科，财务处，保卫处户籍科，学生处，学院教务办，教材科，图书馆办公室，校医院医保办。

根因是地点关键词表里全是空间名词，办公室，会议室，报告厅，教学楼，图书馆，体育馆，中心，广场，楼，厅，场，室，一个处科室办部学院系都没有。片段里找不到任何关键词就直接返回空。

我本机写了个原型试过一次，只补单位后缀并配提交类动作词，能补回十四条而且值和人工判断完全一样，误造零条。下面两组是我实测的结果。

能补回来的（现在都是空的）：

| 原文里的说法 | 现在给 | 应该给 |
|---|---|---|
| 报送至教务处考务科 | 空 | 教务处考务科 |
| 将费用交至财务处收费科 | 空 | 财务处收费科 |
| 签字后交回学院教务办 | 空 | 学院教务办 |
| 到校医院医保办 | 空 | 校医院医保办 |
| 报保卫处 | 空 | 保卫处 |
| 交至图书馆办公室 | 空 | 图书馆办公室 |
| 交回辅导员处 | 空 | 辅导员处 |

这几条现在是对的，一个字都不能变：

| 输入 | 实际 |

## Prompt

```
我又跑了一百条真实通知做测试，发现地点这个字段有二十九条是空的，我把空的那些原文都翻出来看了一遍，发现空的几乎全是一种情况，就是地点写的是行政单位的名字。比如报送至教务处考务科，将费用交至财务处收费科，签字后交回学院教务办，到校医院医保办，报保卫处，交至图书馆办公室，交回辅导员处，这些全都是空的。

我去看了一下代码，地点是靠一张关键词表去截的，那张表里面全是空间名词，办公室，会议室，报告厅，教学楼，图书馆，体育馆，中心，广场，楼，厅，场，室，可是单位名用的那些字，处，科，室，办，部，学院，系，一个都没有。所以整句话里找不到任何一个关键词，就直接返回空了。

我想请你帮我补上这一类，就是行政单位名也能当地点抽出来。我有几个要求想请你一起考虑。

第一，我只想在明确的提交动作词后面去找单位名，比如报送至，报送，交至，交到，报至，报到，提交至，发送至，送至，交于，发至，到，在，报这一类。不要整句话到处乱找，那样很容易把不是地名的内容当成地点。

第二，单位名的结尾要取最靠后的那一个，不是最靠前的。我踩过一次，教务处考务科如果取到前面的处字就变成教务处，后面的考务科丢了，用户跑到教务处还得再问考务科在哪。所以应该取到最右边的结尾。

第三，有些字会和别的词混在一起，需要避开。办字会遇到办理，办法，办公，办事。处字会遇到处理，处长，处的。科字会遇到科目，科研。部字会遇到部门，部分。系字会遇到系统，系列。遇到这些应该跳过，不要当成单位名的结尾。

第四，动作词和单位名中间可能会夹一些别的内容，比如报送自查表至保卫处，中间夹了自查表和至字，比如到所在学院教务办，前面有个所在。这些夹在中间的内容要去掉，只留单位名本身。

第五，有些说法里单位名后面还跟着门牌号，比如在教师教育学院A105举行，应该给教师教育学院A105，不能只给教师教育学院。这条如果不好做可以先不管，你告诉我。

还有几条我想请你帮我守住，这些句子里没有地点，不能凭空造出来。同学们请于11月30日前登录系统完成报名，这一条不能造出报名或者名系。请到教务处办理手续，这一条要给教务处，不能给教务处办理。学校决定在全校范围内开展宿舍安全隐患大排查，这一条本来就应该是空的，不能造出全校范围内。逾期不再受理请尽快办理，这一条不能造出办理。各部门分别组织，这一条不能造出部门或者各部。

你不用把整个文件发给我，只告诉我改哪几处和改成什么就行。我们这个项目之前有一次你给了完整实现，结果覆盖掉了很多已经做好的功能，所以这次麻烦你一定只给改动片段。另外正则请全部用字符类写法，不要用反斜杠加数字那种，之前在这个项目上出过好几次问题。最后请只改地点这一处，日期和材料和面向对象都不要动。
```
