# 076 续 075 修正传参方式与收窄改动范围

## 背景

075 给出的片段方向对，但本机核对发现一处会直接导致功能不生效的错误，
以及一处范围外的自发改写。这一轮把事实讲清楚再要一版。

## 本机已核验事实

`parseOne` 的签名是 `parseOne(text, options = {})`，基准取自 `options.publishedAt`。
`buildItems` 的签名是 `buildItems(rawText, options)`，基准取自 `opts.publishedAt`。
两者第二个参数都是对象，不是日期字符串。075 写成位置参数传字符串，换算拿不到基准。

`.zb-input` 是通用样式类，文本域与单行输入都适用，不需要另换类名。

`handleConfirmSplit` 原来不带 `items` 字段，保存后由 `noticeMigrate` 补出，
075 顺手加了一段补事项的代码，属于范围外改动，应撤回。
