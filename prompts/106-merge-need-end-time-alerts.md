# 106 多条缺结束时间提醒合成一条可展开提示

## 背景

演示时三场活动通知里都没写结束时间，工作台一下子摆出三张一模一样的卡片，
每张都写结束时间待补充，把下面真正要办的事挤到看不见的地方。

提醒计算模块是有离线用例钉着的纯函数，本轮不动它，只在展示层聚合。

## 本机已核验事实

提醒组件的内部状态，已有函数，渲染四行结构，
生产模块现场输出，验收锚，都写在随附的事实材料里。

## 验收要点

第一，三条缺结束时间只出现一张聚合卡片，收起时显示有3项活动未提供结束时间，暂无法判断时间冲突。

第二，只有一项时也走同一张卡片，数字跟着变，没有缺结束时间时整张卡片不渲染。

第三，展开后才看到具体事项，每一项一个跳原文按钮，每一项一个独立的补充结束时间入口，补的是自己那一项。

第四，时间冲突和截止事项集中两类提醒的渲染与条数完全不变。

第五，缺结束时间只影响冲突判断，组件不提供完成或禁用入口，不挡着事项照常办理。

第六，不改提醒计算模块，不改事项卡，不改工作台组件，只输出成对改动片段。

## Prompt

```
演示的时候有三场活动通知里都没写结束时间，工作台一下摆出三张长得一样的卡片，每张都写结束时间待补充，把下面真正要办的事全挤下去了。我想把它们收成一条，收起来的时候只显示一句，有3项活动未提供结束时间，暂无法判断时间冲突。点一下展开才看得到具体是哪几项，每一项都能点进去看原文，也都能单独补结束时间，补的时候要补到这一项自己头上，别像现在这样不管点哪个都补到第一项去。只有一项的时候也走这一条，数字跟着变，一项都没有的时候整张卡片别出现。数字按事项去重后算，同一项别数两遍。时间冲突和截止事项集中那两类提醒原来长什么样还长什么样，条数也别变，别被一起合掉。缺结束时间只是没法判断冲突而已，别挡着这些事项照常办理和标记完成，这个组件里也别加什么完成或者禁用按钮。提醒怎么算是另一块代码的事，那边有离线用例钉着，这次不要动，事项卡和工作台也不要动。请按事实材料里的现场结果写，只发成对片段，别重贴整个文件。
```
