# 043 材料要能一条条勾选，程序自己给的建议不能冒充通知里的要求

## 背景

上一轮事项层跑通了，一条通知能切成好几件事，每件事自己带时间地点材料和状态。同学用了之后提了两个新问题。

第一个，材料那一栏现在是一整行文字，几份材料挤在一起。同学说我想照着这个单子一样一样准备，能不能让我勾，勾完自己记住。

第二个更要紧。同学说界面上写的这些到底哪些是通知里要求的，哪些是你们程序自己加的，我分不出来，我不敢照着做。这一条其实是我的错，程序给的建议和通知原文的要求必须一眼能分开。

## 几条硬约束

第一，材料每一项都要能单独记一个准备好了没有的标记，默认是没准备好。

第二，程序自己生成的建议要单独放一个清单，每一项都带标记说明这是系统建议，绝不能混进通知要求的材料里。

第三，建议只能来自程序自己的通用模板，不许从通知原文里抽一句话当建议。原文里写的东西属于正式要求，走材料那一栏。

第四，通知没说两件事有先后顺序，程序不许自己加一条说必须先办完前一个才能办后一个。

## Prompt

```
上一轮事项层做出来效果很好，同学已经能看清一条通知里有几件事了。这一轮同学又提了两个问题，我先把原话抄给你。

同学说，材料那一栏是好几份东西挤在一行里，我想照着单子一样一样准备，能不能让我勾一下，勾完自己记住，我明天打开还在。

第二个问题同学说得比较重。同学说，屏幕上写的这些，我分不出哪些是通知里要求的，哪些是你们程序自己加的，我不敢照着做。我觉得他说得对，这个必须一眼能分开。

所以这一轮我想请你改一下事项的数据结构，还是改 noticeItems 点 js 那个文件。

先说材料。现在材料是一个字符串的数组，我想改成对象的数组。每一项里面带两样东西，材料的名字，还有这项准备好了没有，默认是没准备好。这样界面上能画成一个可以勾的清单，勾完的状态存在事项里，刷新页面也还在。

有个兼容的事请一起处理。之前存下来的老数据里材料还是字符串的数组，不能直接当成对象用，会出错。请你写一个统一的函数把两种都整理成对象的数组，字符串就补一个默认没准备好的标记。这个函数在生成事项和读老数据的地方都要用上，别漏。

再说建议这块，这是这一轮的重点。我想请你在事项里新增一个建议清单，跟材料完全分开。建议是程序自己给同学的提醒，比如要去交材料的话提醒提前把表填好，要去开会的话提醒提前十分钟到。每一条建议都要带一个标记，写明来源是系统建议，这样界面上能给它画一个不一样的标签。

有几条我特别想请你守住。

第一，建议只能来自你写的通用模板，不许从通知原文里抽一句话当建议。原文里出现的东西那是正式要求，归材料那一栏管。这两边不许串。

第二，建议要根据事项的种类给。要办的手续和要去参加的活动，提醒的内容不一样。

第三，活动这一类事项没有材料要交，建议里不许出现准备材料这类话，那会让同学以为漏了什么。

第四，通知里没说两件事有先后，就绝对不许生成必须先办完前一个才能办后一个这种依赖。我们同学的情况是通知常常只写两个日期，谁先谁后人家自己会看，程序替他规定顺序反而会害了他。所以数据结构里不要出现依赖相关的字段。

下面这些是我一条一条跑出来的结果，请你照着核对，不要自己另算。

第一条原文是助学金那条，两句话，五号下午五点前交纸质申请表到学生工作处A302办公室，八号晚七点在行政楼A302会议室开评审会请班长到场。切出来两个事项。第一个事项名称提交纸质申请表，材料清单里有一项名字是纸质申请表，准备好了没有是没准备好。第二个事项名称参加评审会，材料清单是空的，它的建议清单里不允许出现准备材料这类话。

第二条原文是歌手大赛那条，报名截止十一月十日十七点报名表交到团委办公室，初赛十一月十五日晚六点半在大礼堂举行请参赛选手提前半小时签到。两个事项。第一个材料清单里有一项报名表，没准备好。第二个参加初赛，材料清单是空的。注意提前半小时签到这句话不要被当成建议也不要被当成材料，它只是原文里的说明。

第三条原文是宿舍检查那条，十一月二十日上午九点起后勤管理处对全校学生宿舍进行检查请各寝室配合。一个事项，地点是空的，材料清单是空的。

材料清单的格式再确认一遍。每一项都要有名字，都要有准备好了没有这个标记，默认一律是没准备好。不允许出现只有名字没有标记的情况，也不允许出现只有标记没有名字的情况。

兼容那边的期望是这样。给我一个老数据，材料是字符串数组，里面有一项叫体温监测表，整理完应该变成一项，名字是体温监测表，准备好了没有是没准备好。

建议那边的期望是这样。给我一个要去参加活动的事项，建议清单不能是空的，里面每一项的来源标记都要写着是系统建议。给我一个要办手续的事项，建议清单也不能是空的，同样每一项来源都是系统建议。不管哪一类，建议清单里都不许出现从原文里抄来的句子。

请你只输出改动的那几段代码，不要整个文件重抄一遍。改完我自己跑，跑不过我再回来找你。
```
