# 026 页面上下分区与结果区占满（方案已与用户敲定）

## 需求（用户逐条定过）

1. 整体上下两块，上半「通知原文」约 35%，下半约 65%
2. 上半常显不折叠（要靠它展示字段高亮），高度压矮一点，内容长了内部滚动，宽度保持居中限宽
3. 下半左栏「我的通知」260px 一动不动；右栏「解析结果」占满剩余全部宽度，不能留空格子
4. 结果字段两列栅格，标题、需提交材料、摘要各占一整行
5. 压缩间距，让八个字段尽量一屏放完；实在放不下面板内部滚动
6. 手动修正能力保留，但去掉常显的「编辑」两个字，改成鼠标移上去才出现铅笔，点字段值本身就能改

## Prompt

```
我又发现页面还是不太对，想请你帮我改一下。

我打开看了一下，下半部分那个网格虽然分成三格，可是里面只放了两个东西，第三个格子空着，所以右边有一大块空白。而且上半部分放通知原文的地方太高了，占了差不多半屏，下面显示结果的地方就被挤得只剩一点点，八个字段最后还被截断了，看不到完整内容。

我想请你按下面这个样子改。

第一个是分成上下两块。上面那块放通知原文，大概占页面的百分之三十五，下面那块放左边我的通知和右边解析结果，大概占百分之六十五。上面那块请不要做成可以折叠的，因为我还要靠它展示点字段高亮原文出处这个功能，折叠了就看不见了。高度比现在压矮一点就好，不用改太多，通知原文长了让它在自己那块里面滚动。左右还是保持现在这样居中限宽，不要拉宽，太长的一句话读起来累。

第二个是下面那块。左边我的通知那一条保持二百六十像素宽，什么都不要动。右边显示解析结果的那个组件要占满剩下的全部宽度，不能留下空白的格子。里面那些字段还是按两列排，但是标题、需提交材料、摘要这三个要各占一整行，不要挤在半行里。

第三个是尽量让八个字段在一屏里都看得见。可以把间距和字号压一压，我的想法是正常通知基本不用滚动就能看全。要是遇上特别长的通知实在放不下，就让它在结果面板里面滚动，不要把字号压得看不清。

第四个是每个字段右边那个编辑两个字。这个功能是需要的，因为抽取错了用户要能自己改，这个不能删。但是能不能不要一直显示这两个字，改成鼠标移到那个字段上面才出现一个小铅笔，然后点字段的值本身就能进去修改。这样界面不会看起来像一张表单。

有几件事要请你一定注意。第一个是只改页面布局和显示方式，抽取相关的那些文件一个都不要动。第二个是现有的功能一个都不能删，手动修改，字段高亮，失败原因提示，空状态引导，这些都要还在。第三个是不要新增任何依赖。第四个是项目里没有配置路径别名，引用模块要写相对路径。第五个是那个存各种命令的文件里原有的命令一条都不能删，特别是那条查密钥的，改完请把所有命令都跑一遍把结果一起给我。

回复的时候不要把这个文件整个重新输出一遍，只要告诉我改动落在哪几行，把改之前和改之后的那几行分别写出来，我自己去替换。如果改动分散在好几处，就一处一处分开说清楚，每处都标明大概在第几行。

我不太懂页面布局怎么写的，如果哪里说得不对，你按你的判断来就好。
```

## 验收要点（本机侧）

1. 改动只落在主页文件与结果面板组件，抽取模块与测试脚本零改动
2. 下半区网格列数与实际占用的列数一致，右侧无空格子
3. 上半区高度约 35%，常显不折叠，限宽居中不变
4. 结果字段两列，标题、材料、摘要各占整行
5. 手动修改、字段高亮、失败原因横幅、空态引导四处渲染逻辑仍在
6. 全量 18 条离线命令 exit=0
