# 演示用通知素材

给老师演示时直接从这里复制粘贴。每一条都是校园里平时的写法，
刻意覆盖了几种典型情况，不是挑出来给程序看的。

复制时只复制代码块里的内容，不要连标题和说明一起复制。

## 一、助学金评审（一条通知里两个日期）

截止日和活动日不是同一天，这是知办这次专门解决的。

```text
关于2026年国家助学金评审工作安排的通知
各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室，逾期不再受理。
评审会定于11月8日晚7点在行政楼A302会议室召开，请各班班长届时到场。
```

## 二、校园歌手大赛（报名截止加初赛时间）

```text
第十五届校园歌手大赛报名通知
报名截止时间为11月10日17:00，报名表交到团委办公室。
初赛定于11月15日晚6点半在大礼堂举行，请参赛选手提前半小时到场签到。
```

## 三、主题班会（相对日期，本地换算不花钱）

下周三这种写法本地就能算，不需要调模型。

```text
各班于下周三下午4点召开诚信考试主题班会，地点在本班自习教室。
请班长做好会议记录，会后交回学院学工办。
```

## 四、学籍信息核对（这条没有地点）

有些通知压根没写地点，程序给空是对的，不该硬造一个。

```text
关于核对2026级本科生学籍信息的通知
请各位同学于11月12日前登录教务系统核对个人学籍信息，逾期不再受理。
```

## 五、宿舍安全检查（地点抽不到，手动补一次）

学生宿舍这种泛称，规则宁可留空也不乱猜，正好演示手动修正。

```text
关于冬季学生宿舍安全卫生检查的通知
11月20日上午9点起，后勤管理处将对全校学生宿舍进行检查，请各寝室留人配合。
```

## 六、教材费结算（地点是行政单位名）

```text
2027届毕业生教材费结算通知
请各班学习委员于11月18日前将教材费汇总表交至教务处教材科A105，并携带缴费凭证。
```

## 七、学术讲座（只有活动日没有截止日）

```text
学术讲座通知
定于11月14日下午两点半在图南楼报告厅举办人工智能与城市发展专题讲座。
请感兴趣的师生提前十五分钟到场。
```

## 八、青年大学习（最短的一条）

```text
请全体团员于11月9日前完成本季青年大学习网上主题团课。
```

## 九、紧急通知（明天截止，专门用来演示待办）

这条截止日在三天内，保存之后会自己跳进待办页。

```text
关于紧急报送体温监测表的通知
请各班于明天下午5点前将体温监测表交至学院学工办B203。
```

## 十、多通知批量演示（三条一起粘贴）

切到多通知模式，一整段粘进去，程序自己切成三条。

```text
关于2026年国家助学金评审工作安排的通知
各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室。
评审会定于11月8日晚7点在行政楼A302会议室召开。

第十五届校园歌手大赛报名通知
报名截止时间为11月10日17:00，报名表交到团委办公室。
初赛定于11月15日晚6点半在大礼堂举行。

学术讲座通知
定于11月14日下午两点半在图南楼报告厅举办人工智能与城市发展专题讲座。
```
