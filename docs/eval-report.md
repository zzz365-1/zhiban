## 五、口径说明

本报告中的数字均为本脚本按固定口径自动统计，分母如下：事项数完全正确占比的分母是该组案例条数；时间类型、日期、时间、地点、事项名的正确率分母是该组中参与比对的事项数（即预期事项与实际存在的事项一一配对的数量），预期类型为空字符串的事项不计入时间类型分母；材料漏抽、误抽是件数计数，不是百分比，分母不适用于此两项。

以下情况属于口径分歧，不是程序错误，但仍按错计：人工预期地点写的是完整名称，程序只抽到房间号，或反过来；日期、时间写法不同（如“下午五点”与“17:00”）；预期抽不出某字段而程序给出了值。这类问题在逐条明细的“错误原因”里会标注“口径”二字，统计时仍然算错，以便使用者自行判断是否可接受。

材料名、地点、事项名采用互相包含判定，因为人工预期不可能与程序输出一字不差；日期、时间采用字符串严格相等判定，空对空算对。
