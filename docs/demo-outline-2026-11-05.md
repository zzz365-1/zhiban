# 知办演示提纲（最后一轮定稿）

日期 2026-11-05。用途：给老师与评审看的正式演示，建议 5 到 8 分钟，1920×1080 录制。
只讲一条主线，用两个亮点撑住：**办理路线**和**补充通知更新**。
下面每步的「画面上应该出现」都来自本轮生产构建产物的浏览器实测，不是设想。

---

## 一、演示前准备（不录进视频）

1. 关掉系统通知和无关标签页，浏览器缩放到 100%，窗口设 1920×1080。
2. 打开应用后先清空本机通知，保证从空工作台开始。
3. 把下面两条原文先放在记事本里，录屏时直接复制粘贴，不要现场打字。
4. 变更对比弹窗字号偏小，录到第五步时把浏览器缩放临时调到 125%，录完调回。

---

## 二、两条演示原文

**通知一，助学金评审安排**

```
关于2026年国家助学金评审工作安排的通知
各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室，逾期不再受理。
评审会定于11月8日晚7点在行政楼A302会议室召开，请各班班长届时到场。
```

**通知二，补充通知**

```
关于2026年国家助学金评审工作安排的通知的补充通知
评审会时间改为11月10日下午3点，地点改为行政楼B201会议室，其余要求不变。
```

## 三、七步分镜

| 步 | 操作 | 画面上应该出现 | 讲什么 |
| --- | --- | --- | --- |
| 一 收到通知 | 点「新增通知」，粘贴通知一，点「开始解析」，点「保存到我的通知」 | 详情页上方是通知原文，下方是解析结果与「事项清单」 | 学生收到一条普通校园通知，不注册不登录，原文不上传，直接粘贴就能用 |
| 二 生成办理路线 | 把视口滚到「事项清单」 | 两张事项卡，「提交纸质申请表」标办理截止 11月5日 17:00 学生工作处A302办公室，「参加评审会」标开始时间 11月8日 19:00 行政楼A302会议室；材料单列在「通知要求」，系统建议单列在「系统建议不是通知里的要求」 | 一条通知被拆成两件可办的事，各有自己的时间地点材料，通知要求与系统建议分开，不会把建议当成学校要求 |
| 三 核对原文 | 点事项卡里的时间或地点文字 | 上方原文区自动选中对应那句话，必要时展开「依据」 | 每个字段都能回到原文找到出处，不是模型凭空给的值 |
| 四 完成交表 | 勾上「纸质申请表」，点「标记完成」，切到「工作台」 | 交表显示已办理，统计卡「待办理」从 2 变 1，另一项仍是待办理 | 办完一件就勾一件，统计同步跟着变 |
| 五 收到改期通知 | 点「新增通知」，粘贴通知二，点「开始解析」 | 弹出「这是一条补充通知」，由自己手选要修改的原通知，点「下一步」 | 系统不自动替我改官方通知，必须由本人确认关联哪一条 |
| 六 确认更新 | 看对比表，点「确认更新」 | 对比表只有日期 11月8日改11月10日、时间 19:00改15:00、地点 行政楼A302会议室改行政楼B201会议室三行；「提交纸质申请表」列在「这些保持原样」；确认后切到变更记录并留一条历史 | 只改被提及的字段，已完成的事项不回退，没提到的要求一个字不动，每次更新都留痕 |
| 七 日历同步且完成状态保留 | 切到「日历」，点 11月10日那一格，再切回「我的通知」，最后按 F5 刷新 | 11月8日不再有评审会，11月10日右栏「参加评审会」只出现一次，显示 15:00 与行政楼B201会议室；交表仍是已完成且材料仍勾选；刷新后状态、变更记录、日历都还在 | 新安排只出现一次，旧安排不残留，办过的不会被改期冲掉，数据刷新后仍然在 |

## 四、两个亮点怎么讲

**办理路线**：不是把通知摘成一段摘要，而是拆成「谁在什么时候带什么去哪里做什么」，
每项都能回原文核对，办完可以勾，勾完工作台与日历一起变。
同一条通知里报名截止和活动开始分开管，不会把讲座开始时间误写成提交截止。

**补充通知更新**：真实校园场景里通知常改期。系统先识别这是补充通知，
再由本人手选原通知，逐字段展示变化前、变化后和依据原句，确认后才写回。
已完成事项不回退，未提及要求保持原样，每次确认留一条变更记录，
日历由同一份事项数据重算，所以旧安排自动消失，新安排只出现一次。

---

## 五、收尾一句话

把一条容易看漏、容易改错的校园通知，变成能核对、能跟踪、能同步的办理路线，
模型只负责理解自然语言，日期换算、事项切分、日历构造和冲突判断都交给确定性代码。

## 六、录屏避坑

1. 不要把 API 密钥、`.env.local` 或任何带密钥的界面拍进视频。
2. 演示过程只用上述两条原文，不要临时换素材，避免解析结果不可预期。
3. 第五步之前不要点「取消」，否则会退回未关联状态，画面会断。
4. 第七步的刷新必须真的按 F5，这是证明数据落地的关键镜头。
5. 想补拍重复通知提示，可再粘一遍通知一，会弹「这条通知已经存在」；
   把正文里「报送至」改成「交至」再粘一次，会弹「疑似重复的通知已存在」。
