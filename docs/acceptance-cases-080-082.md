## 三、验收案例与预期

### 浏览器案例，用一条未参与开发的通知

原文：关于2026年秋季校园招聘双选会志愿者补报的通知。请各班于11月12日下午4点前把志愿者补报名表和学生证复印件送到大学生活动中心203室，逾期不再受理。补录说明会定于11月14日晚上7点在图书馆一楼报告厅召开，请报名同学届时到场。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| B1 | 1280×720 打开这条通知的详情 | 原文区在上，解析结果区在下，不再左右分栏 |
| B2 | 原文只有四行 | 上方原文区高度贴合内容，下方结果区占满剩余高度，中间没有大片空白 |
| B3 | 换成二十行以上的长原文 | 上方原文区自身滚动，不把下方结果区顶出屏幕，整页不出现第二根滚动条 |
| B4 | 解析结果字段与事项较多 | 下方结果区自身滚动，顶部状态栏和重新解析保存按钮一直可见 |
| B5 | 点折叠再点展开 | 折叠后是一条横向细条，不出现竖排文字，展开恢复原样 |
| B6 | 滚到解析结果底部 | 分类留在字段区，事项清单整宽显示，卡片不再压在半列里，文字不截断 |
| B7 | 打开新增通知弹窗 | 发布日期空态不再出现英文字母，显示中文示例文字 |
| B8 | 发布日期填 2026年11月3日 并解析写下周三的通知 | 能换算成具体日期，行为与原来填标准写法一致 |
| B9 | 发布日期留空解析同一条通知 | 仍显示待确认，不按今天偷偷换算 |
| B10 | 把含明确日期的通知填基准再解析 | 结果与不填完全一致 |
| B11 | 保存到我的通知后刷新 | 发布日期和解析结果都还在 |
| B12 | 全页面扫标签文字 | 找不到拉丁字母混在中文标签里的写法，含摘要分类小标记与来源标签 |
| B13 | 1920×1080 重复 B1 B2 B6 | 同样上下分区，无水平滚动，无溢出，信息完整 |
