# 演示视频录制模板（2026-11-04 版）

**这一份取代 `docs/video-notices-and-steps-2026-11-03.md`**，录视频照这一份走。
页面上能点的按钮文案、每条通知抽出来的值，都是当天在当前生产构建产物上实跑过的。

相比旧版改了这些，旧稿别再照着念：

- 详情页已经是**原文在上、解析结果在下**的上下分区，不是「双栏」。
- 新增通知弹窗多了选填的**「通知发布日期」**，填了才能把「下周三」换成具体日期，这与密钥无关。
- **点标题能跳回原文高亮**，且不再误报「原文里没找到这段内容」。
- 找不到原文出处的换算值会**给中文说明**，不再一律报红字。
- 多通知结果页**自己带保存按钮**（本轮新补），不用回详情页找。
- 来源标签统一成「本地识别」。

---

## 零、录前准备（三分钟）

1. 服务起在 3000 端口，`npm run dev` 或 `npm run start` 都行，浏览器打开 http://localhost:3000
   窗口建议 1280×720，缩放调到 100%。
2. **先清空状态**，否则片头拍到一堆旧数据。浏览器控制台执行：

```js
localStorage.removeItem("zhiban.welcomed");
localStorage.removeItem("zhiban.notices.v1");
location.href = "/";
```

3. 全程**不配密钥也能跑通**，来源标签会显示「本地识别」。别在演示现场改 `.env.local`。
4. **绝对不要把密钥、`.env.local` 内容、终端里的 Key 拍进画面**。
5. 通知素材里不含真实姓名、学号、手机号，界面不脱敏，别临时换成真实信息。

## 一、通知素材（13 条，直接复制代码块）

每条后面一行是生产模块本机实测值，不是预期值。

### A 主线：一条通知带出十几个功能点 ★

```text
关于2026年国家助学金评审工作安排的通知
各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室，逾期不再受理。
评审会定于11月8日晚7点在行政楼A302会议室召开，请各班班长届时到场。
```

实测：截止 **11月5日 17:00**、活动 **11月8日 19:00**、地点 **学生工作处A302办公室**、
材料 **纸质申请表**、对象 **各班**、分类 **行政**、拆 **2 条事项**（提交纸质申请表、参加评审会）、
不是补充通知。

能拍：双日期分开、中文数字时间、地点材料分类、**上下分区**、来源标签、点标题定位、
点字段跳原文、换算说明、手动改字段、标记完成、材料勾选、待办、日历、搜索筛选、
整理成文字、刷新保留。

### B 标题定位与「原文写法直接命中」 ★

```text
第十五届校园歌手大赛报名通知
报名截止时间为11月10日17:00，报名表交到团委办公室。
初赛定于11月15日晚6点半在大礼堂举行，请参赛选手准时到场签到。
```

实测：**11月15日 18:30**（晚6点半）、11月10日 17:00、团委办公室、报名表、
2 条事项（提交报名表、参加初赛）、分类活动。

这条原文直接写了 `17:00`，点这个时间会**直接高亮原文**；A 写的是「下午5点」，
点解析出来的 `17:00` 则会给**二十四小时制换算说明**。两条连着拍就是一组漂亮的对比。

### C 相对日期与发布日期基准 ★

```text
关于开展宿舍安全月活动的通知
请各班于下周三下午4点前将活动计划表交至学院学工办A201。
```

实测：日期 **下周三**、时间 **16:00**、地点 **学院学工办A201**、材料 **活动计划表**、1 条事项。

两个镜头：

- **发布日期留空**：保持「下周三 16:00 待确认」，提示「日期待确认，请补充发布日期以便换算」。
- **填 `2026年11月3日`**：显示 **2026年11月11日 16:00**（生产模块 `resolveRelativeDate` 当场算出
  `2026年11月11日`），待办和日历都用这个日期。

口播别说成「只有接模型才会换算」，那是旧口径。留空不换算是不许按今天偷算，不是没接密钥。

### D 没有地点：宁缺勿滥

```text
关于核对2026级本科生学籍信息的通知
请各位同学于11月12日前登录教务系统核对个人学籍信息，逾期不再受理。
```

实测：地点 **空**、截止 11月12日、分类教务、1 条事项。

### E 行政单位名做地点

```text
2027届毕业生教材费结算通知
请各班学习委员于11月18日前将教材费汇总表交至教务处教材科A105，并携带缴费凭证。
```

实测：地点 **教务处教材科A105** 整串保留、材料 **教材费汇总表、缴费凭证** 两件。

### F 只有活动日没有截止日

```text
学术讲座通知
定于11月14日下午两点半在图南楼报告厅举办人工智能与城市发展专题讲座。
请感兴趣的师生届时参加。
```

实测：日期栏 **11月14日 14:30**（下午两点半）、地点图南楼报告厅、事项「参加讲座」。
这条没有截止日，按行动日口径进待办和日历。

### G 最短的一条

```text
请全体团员于11月9日前完成本季青年大学习网上主题团课。
```

实测：截止 11月9日、地点空、1 条事项。

### H 紧急截止：待办倒计时（明确日期）

```text
关于紧急报送体温监测表的通知
请各班于11月5日下午5点前将体温监测表交至学院学工办B203。
```

实测：截止 **11月5日 17:00**、地点学院学工办B203、材料体温监测表、1 条事项。
`11月5日` 是 2026-11-04 的明天。**隔天再录就把它改成录制当天的明天**，否则会显示已过期，
红色倒计时就拍不到了。待办里的「剩 N 小时」随录制时刻变化，别念死数字。

### I 多通知批量（三条一起粘，中间空一行）★

```text
关于2026年国家助学金评审工作安排的通知
各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室。
评审会定于11月8日晚7点在行政楼A302会议室召开。

第十五届校园歌手大赛报名通知
报名截止时间为11月10日17:00，报名表交到团委办公室。
初赛定于11月15日晚6点半在大礼堂举行。

学术讲座通知
定于11月14日下午两点半在图南楼报告厅举办人工智能与城市发展专题讲座。
```

浏览器实测：弹切分确认 **「识别到 3 条通知」**、按钮 **「解析这 3 条」**；
确认后结果页 **「共 3 条结果」**、按钮 **「保存 3 条到我的通知」**、不再挂
「内容已修改，待重新解析」；点保存后落盘 **3 条**，事项数 **2 / 2 / 1**，
三条来源标签都是「本地识别」。

### J1 原通知（补充通知演示前半段，必须先保存）

```text
关于举办2026年校园心理情景剧大赛的通知
请各学院于11月20日17:00前将报名表报送至团委办公室。
决赛定于11月28日晚7点在大礼堂举行，请参赛队伍准时到场。
```

实测：活动 11月28日 19:00、团委办公室、报名表、2 条事项（提交报名表、参加决赛）。

### J2 补充通知（后半段，接在 J1 之后）

```text
关于校园心理情景剧大赛的补充通知
原定11月28日晚7点的决赛调整至12月1日下午2点，地点改为大学生活动中心报告厅，其余安排不变。
```

实测：判为补充通知，抽出改期到 12月1日 14:00、地点大学生活动中心报告厅。
浏览器实测：J1 保存后粘 J2 会弹 **「这是一条补充通知」／「请选择它要修改的原通知」**，
选项里列出「关于举办2026年校园心理情景剧大赛的通知」和 **「2个事项」**，
有「下一步」「取消」，**不会误报成重复通知**。

### L 纯告知：不该拆就不拆

```text
我校王芳老师荣获2026年度校级教学能手称号，特此通报。
```

实测：**0 条事项**、所有字段空，走零事项空态。用来讲宁缺勿滥的边界。

### M 换算说明备用素材 ★

```text
关于开展校园读书分享会的通知
请各班于11月28日下午5点前把推荐书目表交到图书馆一楼服务台。
```

实测：11月28日 17:00、地点图书馆一楼、1 条事项。
浏览器实测：点解析结果里的 `17:00` 会出现
**「这里是换算后的二十四小时制写法，原文里可能写作另一种时间说法。」**，
且不出现「原文里没找到这段内容」的报错。A 也能拍这个，M 是备用。

## 二、分镜顺序（照着点就行）

带 ★ 的是本轮新增或修好的功能，时间紧就优先拍这些，再加第 2、3、21 步。

| 步 | 操作 | 拍到什么 | 一句话口播 |
|---|---|---|---|
| 1 | 欢迎页点「进入工作台」 | 欢迎页、空状态 | 从一个干净的空白开始 |
| 2 | 点「新增通知」，粘 **A**，点「开始解析」 | 双日期、时间、地点、材料、对象、分类、2 条事项、来源「本地识别」、**原文在上解析结果在下的上下分区** | 一条通知里两个日期，一个要赶一个要到场，现在分开管 |
| 3 | 点「保存到我的通知」 | 保存、已保存状态 | 存下来才进待办和日历 |
| 4 ★ | 点列表里这条通知进详情 | 上下分区，原文区可折叠，解析结果整宽、可滚动 | 内容再多也不挤，长通知自己滚 |
| 5 ★ | 点解析结果里的**标题** | 原文首行「关于2026年国家助学金评审工作安排的通知」被选中高亮，**没有红字报错** | 标题也能点回原文看出处 |
| 6 | 点地点「学生工作处A302办公室」 | 跳回原文对应位置高亮 | 每个值都能对回原文 |
| 7 ★ | 点「17:00」（A 原文写的是下午5点） | 出现**二十四小时制换算说明**，不误报「原文没找到」 | 换算过的会解释清楚，不装作原文就这么写 |
| 8 | 鼠标移到某字段点铅笔，改内容回车 | 手动修正，来源标签跟着变 | 抽不准的允许改，改完标明是谁给的 |
| 9 | 点「标记完成」，勾材料，试「无需办理」再撤销 | 事项状态、材料勾选 | 办到哪一步自己记 |
| 10 | 切「待办」「工作台」 | 需要关注三项统计、待办列表 | 快到期的才来打扰你 |
| 11 | 切「日历」，翻上个月下个月，点某一天 | 月视图、当天事项 | 按日期落进格子 |
| 12 | 顶栏「搜索通知」输关键字，点分类下拉 | 搜索、分类筛选 | 通知多了能找能筛 |
| 13 | 点「整理成文字」 | 一段可直接发班群的文字、复制 | 给同学看的版本不用贴原文 |
| 14 | 按 **F5** 刷新 | 通知与状态都还在 | 数据存浏览器本地，不传服务器 |
| 15 ★ | 粘 **C**，发布日期**留空**解析 | 「下周三 16:00 待确认」、橙色「请补充发布日期以便换算」 | 没有基准就宁可不瞎猜 |
| 16 ★ | 同一条，填 `2026年11月3日` 再解析 | **2026年11月11日 16:00**，提示消失，待办日历同步 | 给了发布日期就能落到日历，跟密钥无关 |
| 17 ★ | 粘 **B** 解析，点标题，再点 `17:00` | 标题高亮、时间**直接高亮原文**（与第 7 步形成对比） | 原文怎么写就怎么定位，换算过的才解释 |
| 18 | 依次粘 **D E F G**，每条只看解析结果 | 地点留空、行政单位名整串、行动日、最短通知 | 各种写法都照顾到，拿不准的宁可留空 |
| 19 | 粘 **H** 解析保存，切待办 | 红色倒计时「剩 N 小时」 | 快到期的会自己冒出来 |
| 20 | 粘 **L** 解析 | 0 事项、不硬造 | 纯通报不给你造假待办 |
| 21 ★ | 切「多通知」模式，粘 **I**，点「开始解析」→「解析这 3 条」→「保存 3 条到我的通知」 | 识别到 3 条通知、共 3 条结果、**结果页自带保存按钮**、落盘 3 条各有事项 | 班群一次转发好几条，整段粘进去一次存好 |
| 22 ★ | 粘 **J1** 解析保存，再粘 **J2** 点解析 | 「这是一条补充通知」关联弹窗、列出原通知和「2个事项」、下一步 | 收到补充通知，先问它改的是哪条 |
| 23 | 选对选项点「下一步」，看「变化前／变化后／依据原句」，点「保持原样」再看，最后「确认更新」 | 前后对比、逐项决定 | 改了什么一眼看清 |
| 24 | 切「变更记录」看修改历史 | 变更留痕、当时的补充通知原文 | 每次改动都留痕 |
| 25 | 收尾一句：全程没配密钥 | 来源标签「本地识别」、降级路径 | 不用申请密钥，评委也能复现 |

**不用每条都保存**。第 18、20 步只解析看结果即可，存太多容易触发「与已有通知重复」弹窗，
打断录制。第 22 步之前列表里已经有别的通知，关联弹窗可能列出多个候选，
**认准「校园心理情景剧大赛」那条再点下一步**。

## 三、现场别踩的坑

1. **别把「提前」写回素材**。变更词表把「提前」当改期词，凡是「提前半小时到场」
   都会在列表非空时误弹关联窗。A、B、F、J1 已经换成「届时」「准时」，照抄别改回去。
2. **补充通知必须先有原通知**。列表空的时候粘 J2 不会弹关联窗，会走普通解析。
3. **发布日期留空时**相对日期一律「待确认」，不会进倒计时。填了基准才换算，
   **与密钥无关**。H 想拍倒计时仍要用明确日期。
4. **H 的日期跟着录制当天改**，隔天录就把 `11月5日` 换成当天明天。
5. **演示前一定清空列表**，不然左列一堆旧数据，还可能触发查重弹窗。
6. **别用带身份证号、学号、真实姓名的通知**，界面不脱敏；**别把密钥拍进画面**。
7. **别临时改密钥、别改代码**，改了要重启服务，容易当场翻车。
8. 1920 宽屏下多通知结果页右侧有留白，是已登记的视觉项，镜头别在那儿停太久。

## 四、没验证过的别拍

- 「正在解析」的转圈加载态：代码里有，没抓到稳定的可见中间态。
- 时间冲突、截止事项集中、结束时间待补充这三类提醒的独立画面：没实测。
- 日历 ICS 导出：**界面入口已移除**，只剩命令行 `npm run validate:ics`，别在视频里找按钮。
- 模型路径的真实调用：需要使用者自己的密钥，本流程全程无密钥。
- 手动编辑解析字段后，事项清单、日历、待办**不会同步重算**，别拍「改完日历跟着变」。
- 补充通知改期的跨年、中文数字日期写法：没覆盖，别自创素材演这段。
