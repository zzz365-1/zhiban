# 环境准备清单

> 适用阶段：项目开工前  
> 预计耗时：40 分钟（主要花在下载等待上）  
> 重要：这份文档里的每一步都可以跳过理解，照做即可

---

## 一、我们先搞清楚为什么要装这三样

你完全不懂这些东西也没关系，先记住一个类比：如果把我们的项目比作**开一家餐厅**——

| 软件          | 通俗比喻       | 它到底干什么                                                                                        | 为什么非装不可                                 |
| ----------- | ---------- | --------------------------------------------------------------------------------------------- | --------------------------------------- |
| **Node.js** | 灶台和燃气      | 让 JavaScript 代码能在你电脑上真正跑起来（本来它只能在浏览器里跑）。装的时候会**顺带装好 npm**——npm 是"下载现成零件"的工具，我们项目里大量现成组件都靠它拉下来 | 没有它，代码就是一堆文本文件，永远只是一堆字                  |
| **Git**     | 监控录像 + 存档点 | 记录每一次代码改动：谁改的、改了哪、什么时候改的，随时能回退到任意历史版本                                                         | 比赛 25% 的分数直接押在它身上。要求"禁止一次性提交全量代码"，靠的就是它 |
| **VS Code** | 案板和刀具      | 一个专门写代码的编辑器。代码会显示彩色区分关键词，能直接在里面开终端敲命令，哪里写错会画红线                                                | 用记事本也能写，但那相当于用指甲刀切菜                     |

**再次强调：Python 不需要装，一个都不要装。** 网上 AI 教程提到 Python，那是训练模型用的路子。我们做网页应用，属于 JavaScript 的世界，发动机是 Node.js。两者毫不相干。

## 二、安装顺序（严格按 1→2→3 来）

### 第 1 步：装 Node.js（最重要，最先装）

1. 打开网址：`https://nodejs.org`
2. 页面上会看到两个大按钮，一定看清再点：
   - 左边绿色 **LTS** 版（写着"推荐给大多数用户"）→ **点这个**
   - 右边 **Current** 最新版 → 不要点，可能有坑
3. 下载得到一个 `.msi` 文件，双击运行
4. 一路 Next，但在 **Destination Folder（目标文件夹）** 这一步停一下：点 **Change...**，把路径改成

```
D:\nodejs
```

> **为什么推荐 `D:\nodejs` 而不是 `D:\Program Files\nodejs`**：一是路径短，二是避开了带空格的目录——空格在某些构建脚本里会引发莫名其妙的报错，属于能躲就躲的坑。当然这只是**运行环境**的位置，跟我们的项目目录 `D:\zhiban` 是两回事，互不干扰。

5. 剩下的步骤全部 Next 到底，**但请留意下一个画面（重要，见下方警告）**

> ### 必须跳过的一步：Tools for Native Modules
>
> 往下点会出现一个标题类似 **"Tools for Native Modules"** 的页面，上面会提议自动帮你装 Chocolatey、Python、Visual Studio 生成工具等一堆东西，甚至可能自动弹出命令行窗口开始下载。
>
> **一律取消勾选 / 直接关掉弹窗，什么都不要装。**
>
> 这正是你之前担心的 Python 会自己跑出来的地方——它是给需要编译 C/C++ 底层模块的场景准备的，**我们的项目一个都用不上**。装了不仅白占几个 G 空间，还会拖慢安装十几分钟，甚至可能引入版本冲突。
>
> 正确做法：取消勾选 → Next → 直到 Finish。

> 官网下载慢的话，改用国内镜像：`https://npmmirror.com/mirrors/node/`，找 `v26.x.x` 的 LTS 版本，选 `node-v26.x.x-x64.msi` 下载。

> **别踩的坑**：页面上那一大块带行号的代码（`docker pull node:26-alpine` 之类）是给服务器用容器方式部署的方案，用了它还得先装 Docker Desktop 这个很重的软件。**我们完全不需要，无视它。** 下载区的 "Windows 安装程序(.msi)" 才是我们要的。
>
> 参考：Node.js 当前 LTS 版本为 v26.13.0（以你打开官网时实际显示为准）。

### 第 2 步：装 Git

**背景**：Git 官网 `git-scm.com` 的下载按钮实际指向 GitHub，国内直连基本都会超时报错（表现为页面提示 `github.com 响应时间太长` 或 `ERR_CONNECTION_TIMED_OUT`），别浪费时间反复刷新。

**直接用已验证可用的国内镜像直链**（淘宝源，实测 HTTP 200，文件 63.6 MB）：

```
https://cdn.npmmirror.com/binaries/git-for-windows/v2.56.0.windows.1/Git-2.56.0-64-bit.exe
```

把它粘到浏览器地址栏回车即开始下载，得到 `Git-2.56.0-64-bit.exe`。下载慢的话丢进迅雷会快很多。

拿到安装包后双击运行，一路 Next，**但这两处务必停下来改**：

| 步骤 | 默认值 | 改成 | 原因 |
|---|---|---|---|
| Destination Location | `C:\Program Files\Git` | `D:\Git` | 统一装 D 盘（文件夹不存在会自动建） |
| Choosing the default editor | **Vim** | **Notepad 或 Notepad++**（下拉里挑任意带图形界面的都行） | 提交时若忘了带 `-m` 消息会掉进 Vim，新手极难退出来（真遇上了按 Esc、输入 `:wq` 再回车）。换成任何图形化编辑器即彻底免疫 |

其余全部保持默认，看到 **Git Credential Manager** 保持勾选不要动——后面往 GitHub 推代码要靠它。

> 注意：Git 官网页面下方推荐用 winget 或 **Chocolatey** 命令行安装，不要采用。Chocolatey 正是我们在 Node.js 安装时特意跳过的工具。

### 第 3 步：装 VS Code（放最后装）

1. 打开网址：`https://code.visualstudio.com`
2. 点大大的 Download 按钮
3. 双击运行安装，**注意这一步**：
   - 勾选 **"Add to PATH"**（加到环境变量）→ 建议勾上
   - 其他勾选项随意
4. 安装完成后打开 VS Code
5. 如果界面是英文想换中文：按 `Ctrl + Shift + X` 打开扩展面板 → 搜 `Chinese` → 装第一个"中文(简体)语言包" → 重启即可

## 三、装完必做：把下载源换成国内镜像（省时间的关键一步）

**这一步千万别跳。** 不换的话，后面装项目依赖时会从国外服务器下载，速度可能慢到几分钟卡一字节，甚至直接超时失败。

操作：

1. 按 `Win` 键，输入 `cmd`，回车，打开一个黑窗口（终端）
2. 原样粘贴下面这行命令，回车：

```
npm config set registry https://registry.npmmirror.com
```

1. 它会安静地没有输出，这就说明成功了。

## 四、怎么验证三样都装好了

在同一个黑窗口里，依次敲这三行，每行敲完按回车：

```
node -v
```

```
npm -v
```

```
git --version
```

正常的话会分别显示类似 `v20.18.0`、`10.8.2`、`git version 2.47.0` 这样的版本号。

**把这三行显示的完整内容复制发给我。** 只要版本号出来了，就说明环境全部就位，我立刻开工。

> 如果提示"不是内部或外部命令"，说明某个软件没装上或没加到 PATH，把报错信息截图发我，不要自己折腾。

## 五、DeepSeek Key 怎么拿（充值 20 元）

### 操作步骤

1. 打开 `https://platform.deepseek.com`（注意：是 **platform** 开头，不是普通聊天的 chat.deepseek.com）
2. 用手机号注册并登录
3. 在左侧菜单找 **API Keys**（有的版本叫"接口密钥"）
4. 点 **创建 API Key**，会给一串以 `sk-` 开头的字符串
5. **立刻复制保存到本地**（这个串只在创建时完整显示一次，关掉就再也看不全了，只能删掉重建）
6. 找"充值"或"账户余额"入口，充值 20 元

### 关于模型名（这里有个大坑，务必看）

我查了 DeepSeek 官方定价文档，**旧的 `deepseek-chat` 和 `deepseek-reasoner` 这两个模型名已于 2026 年 7 月 24 日正式退役，现在已经完全不可用了**。网上大量老教程还在教你填这两个名字，照抄会直接报错。

我们项目统一用：

```
模型名：deepseek-flash
接口地址：https://api.deepseek.com
```

`deepseek-flash` 对应 DeepSeek-V4.1-Flash，官方定价（非高峰时段）大约是输入 0.15 美元/百万 tokens、输出 0.60 美元/百万 tokens。**按我们一次解析通知的体量算，调用一次大概三分钱都不到**，20 元充值足够跑完整场比赛。

> 保险起见，你在控制台看一眼自己的"可用模型列表"确认一下。平台政策变动快，以你控制台实时显示为准。

### 关于免费额度

有第三方汇总资料提到 DeepSeek 新用户会赠送 300 万到 500 万 tokens（不同来源说法不一致，且通常 30 天内有效）。如果给你了就用，但别指望它——**它大概率撑不到 11 月 18 日交作品**。充 20 元才是稳的。

## 六、安全须知（这是评分表里的扣分项，必须守住）

我们的项目最终要提交到**公开**的代码仓库。GitHub 上有自动化的机器人全天扫描公开仓库里的 API Key，**一旦 Key 出现在仓库里，几分钟内就会被扫走盗用**。

三条铁律：

1. **绝对不要把 Key 粘贴给我**，也不要粘贴到任何聊天窗口、截图或文档里
2. Key 只写进项目根目录下的 `.env.local` 文件，这个文件我会在 `.gitignore` 里排除掉，永远不会被提交
3. 仓库里只会出现 `.env.example` 模板文件，内容是这样（不含真实 Key）：

```
DEEPSEEK_API_KEY=your_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

如果哪天不小心把 Key 泄露了，第一时间去控制台**删掉那个 Key 重建一个新的**，别犹豫。
