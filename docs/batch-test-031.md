# 031 大批量真实链路测试素材

说明：这 60 条是本次新建的通知，包含真实校园里常见的各类写法与边界情况。

每条下面写了「我判」，那是本助手逐条人工读原文给出的判断，不是标准答案（Dec-031 说过期望值本身也可能是错的）。
所以本轮的重点不是拿它去判对错，而是做**不依赖期望值的自动检查**：
抽出来的值必须能在原文里找到出处，日期必须能被解析成合法日期，来源与耗时必须可查。
两者不一致的地方会单独列出来，由人来定谁对。
