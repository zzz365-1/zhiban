# 测试用例集

维护说明：每次修改抽取逻辑后重跑本文件全部用例，比对预期值。日期相关的预期值基于基准日 2026-10-31。

## 一、用例清单

| 编号 | 名称 | 设计目的 | 本地规则 | 是否触发模型 |
|---|---|---|---|---|
| A | 消防演练 | 紧急红色状态 | 成功 | 否 |
| B | 期中教学检查 | 一周内黄色状态 | 成功 | 否 |
| C | 图像采集 | 时间充裕常态 | 成功 | 否 |
| D | 优秀学生干部 | 已过期置灰 | 成功 | 否 |
| E | 新生资格复查 | 本地够好时不调模型，验证混合架构省流 | 成功 | 否 |

| G | 临时停课 | 相对日期，模型应拒绝换算 | 失败 | 是 |

## 三、E 到 J 进阶六条

### E 新生资格复查（本地直取，不触发模型）

```
关于报送2026级新生入学资格复查材料的通知
各学院、全体新生辅导员：
根据教育部有关规定，现开展2026级新生入学资格复查工作。
请各学院于2026年11月12日17:00前将《新生入学资格复查情况汇总表》纸质版报送至行政楼A208学籍管理办公室，电子版同步发送至邮箱 xueji@example.edu.cn。
联系人：赵老师 13800000001
教务处
二〇二六年十月三十一日
```

预期：截止日期 2026年11月12日，时间 17:00，地点 行政楼A208学籍管理办公室，来源手动导入，剩余 12 天常态。

### F 校园读书月（模型兜底）

```
关于举办第十九届校园读书月的通知
各班级：
图书馆定于2026年11月8日9:00在图书馆一楼多功能厅举办读书月开幕式，届时邀请知名作家到场签售。
请有意参加的同学以班级为单位填写《参与意向登记表》，由班长统一于2026年11月6日12:00前发至邮箱 tushuguan@example.edu.cn。
图书馆
二〇二六年十月三十日
```

预期：本地规则抽不出截止日期，由模型补出 2026年11月6日 12:00，分类 活动，来源 AI 辅助，剩余 6 天黄色。
**注意**：必须挑中 11月6日 交表，而非更靠前的 11月8日 开幕式。

### G 临时停课（模型应拒绝换算）

```
关于临时停课的通知
各位同学：
因校内供电线路检修，本周五下午的工程制图课程暂停一次，补课时间另行通知。
请各班班长收到后于明天中午12点前回复确认至班级群。
机械工程学院
二〇二六年十月三十一日
```

预期：模型返回 deadline 为「明天」，无法换算成具体日期，列表显示「无截止日期」。**这是正确行为**，不得判定为缺陷。

### H 自习室调整（全文无截止日期）

```
关于自习室开放时间调整的通知
全体同学：
为配合冬季用电管理，三楼自习室开放时间自即日起调整为每日8:00至22:30，节假日照常开放。
请同学们合理安排学习时间，离馆时请自觉带走个人物品。
后勤保障处
二〇二六年十月二十九日
```

预期：截止日期为空，列表显示「无截止日期」，导出按钮禁用。

### I 大创中期检查（复杂多动作）

```
关于开展2026年大学生创新创业训练计划项目中期检查的通知
各项目负责人及指导教师：
学校定于2026年11月28日14:00在大学生创新创业中心二楼报告厅举行中期答辩。
各项目组须于2026年11月25日17:00前提交中期进展报告及经费使用明细表至邮箱 cxcy@example.edu.cn。
纸质材料一式三份于答辩当日现场提交。
逾期未提交材料的项目视为自动放弃后续经费支持。
创新创业学院
二〇二六年十月三十一日
```

预期：模型给出 2026年11月25日 17:00，不得误取 11月28日 答辩日，也不得取答辩当日的 14:00。剩余 25 天常态。

### J 催缴学费（半相对写法）

```
关于催缴2026至2027学年学费的通知
各学院、全体在校生：
截至目前仍有部分同学未完成学费缴纳。
请欠费同学务必于本月25日前完成缴费，逾期将影响选课及成绩查询。
缴费方式详见财务处公众号。
财务处
二〇二六年十月三十一日
```

预期：模型返回 deadline 为「本月25日」，不可换算，显示无截止日期。

### K 冬季征兵（有日期无时刻，本地直取）

```
关于2026年冬季征兵报名工作的通知

根据上级征兵工作部署，2026年冬季征兵工作现已启动。
请有意参军的同学携带本人身份证和学生证，于2026年11月14日前到行政楼B105武装部办公室登记报名，逾期不再办理。
联系电话 13800000002
武装部
二〇二六年十月三十一日
```

预期：本地规则抽全，不触发模型，时间为 null，剩余 14 天，导出按钮可用。

### L 校园马拉松（有日期无时刻，双日期）

```
关于举办第七届校园马拉松的通知
各学院、全体在校师生：
校工会定于2026年11月30日上午在东体育场举行第七届校园马拉松。
请各单位于2026年11月27日前将参赛名单汇总报送至体育部邮箱 tiyu@example.edu.cn，报名表见附件。
校工会
二〇二六年十月三十日
```

预期：本地规则因原文是「27日前」这种紧贴写法，命中后置判定，成功抽出 11月27日，不触发模型，剩余 27 天。

### M 助学金复核（有日期无时刻无地点）

```
关于开展2026年国家助学金申请材料复核的通知
各学院：
学校将对2026年国家助学金申请材料进行复核。
请相关同学准备好家庭经济困难证明和相关佐证材料，务必在2026年11月9日前完成提交，逾期不再补办。
学生资助管理中心
二〇二六年十月三十一日
```

预期：本地缺地点，触发模型，模型给出 2026年11月9日，时间为 null，来源 AI 辅助，剩余 9 天。

## 四、已知能力边界

十条用例中有三条（G、H、J）拿不到可用的截止日期，原因是**原文没有给出可换算的基准日期**。
模型坚守「不编造」原则，宁可留空也不猜。

这是当前的产品短板，而非缺陷。可行的改进方向：在调用模型时把当天日期作为已知信息提供给它，
使其能把「明天」「本周五」「本月25日」换算成具体年月日。此改动尚未实施。
