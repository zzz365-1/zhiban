## 四、必须遵守的规矩（违反会出事）

**协作分工**：代码一律由对话式 AI 生成，人负责提需求、验收与拍板。
这是本项目对外呈现的唯一形态，也是"过程可复现"评分项的基础——
评委拿 `prompts/` 里的归档可以自己复现出代码。
本侧负责架构设计、提示词编写、文档撰写与本机验收。

**本侧不得触碰代码文件（2026-11-02 明确）**：包括新增、修改、撤销、删除在内的一切代码改动，
都由对话式 AI 生成或由人执行。本侧遇到需要改代码的情况（哪怕是撤销一次错误覆盖），
**只给出命令原文，由人自己执行**。职责边界固定为：
只读取证、跑测试、写提示词、写文档、指出该跑哪条命令。

**提示词书写铁律**（写给外部模型看的正文）：学生第一人称求助口吻，
叙述"我遇到什么现象"；不预设技术细节；允许示弱；
**正文禁用一切排版符号，只能用逗号、句号、问号**（顿号、引号、括号、冒号、
书名号、反斜杠、星号全部不许出现）。涉及文件名不说出名字，改用命令名锚定。
改完必须跑 `npm run check:prompt` 验证。

**新对话防回退铁律（2026-11-02 事故后新增，最高优先级）**：
给新对话的 AI 发历史分享链接让它"自己熟悉"，它会挑错进度、从零重做。
**每次开新对话必须先粘 `docs/new-session-brief.md` 里的开场白**，再粘当轮需求。
开场白里已写死六条：禁止完整实现、禁止删功能、没有路径别名、
抽取模块真名是 `extractNotice.js`、只输出改动片段、正则用字符类。

**应用 AI 改动前先看 diff 规模**：`git status -sb` + `git diff --numstat`。
**删除行数超过新增行数两倍以上 = 回退信号**，先问再动，不要直接应用。

**验证铁律**：
- AI 交付的代码一律先在本机实跑，不靠截图（Dec-014）
- 测试脚本必须 import 生产模块，禁止另抄一份相似的（Dec-022）
- 断言前不许归一化，归一化会把失败洗成通过（Dec-023）
- 安全网必须注入坏实现验证真会报红，不能永远全绿（Dec-024）
- 失败用例要同时核输入、描述、期望三样（Dec-039）
- 禁止把期望值改成实际值了事（Dec-031）
- 正则一律用字符类，禁止反斜杠加数字（Dec-013）
- package.json 原有命令一条不能删，尤其 `check:key`（Dec-027）

**推送边界**：个人失误复盘只留本地 `docs/journal/self-reflection-local.md`（已 gitignore），
不进 GitHub；README、技术文档、Prompt 归档等正式交付物必须推送。

**日志**：后台静默写 `docs/journal/`，不汇报内容、不 present_files。

**录屏标注**：每次给行动方案，末尾附 `🎥 录制：要 / 不要 —— （录什么，从哪到哪停）`。

## 五、当前第一个任务：019g 相对日期后缀与单位边界

**提示词已归档**：`prompts/019g-relative-suffix-and-unit.md`

**本机取证结果**（基准 2026-11-02 周一，已实跑）：

能算：三天后、两天后、一周内、两周后、一个月后、下周三、十五天后、两周之内、一个月之内

返回空：下周三之前、下周三前、本周五中午前、三天之前、三天以前、
本月底前、大后天之前、半年后、半个月后、一季度后

**根因**：`relativeDate.js` 全部用 `^...$` 全串精确匹配，
结尾多出「之前/前/以前」后匹配不上，返回 null 并回落给模型做日期算术
——正是 018 想消灭的那类概率性错误。

**最大的陷阱（必须守住）**：「三天前」说的是**过去**，不是将来的截止日。
日期型（下周三前、本月底前）可以剥后缀；
**数量型带「前」必须保持返回 null**，绝不可当成加三天。宁缺勿滥优先于覆盖率。

**验收要点**：
1. 下周三之前、下周三前、本周五中午前、本月底前、大后天之前 均能算出日期
2. 三天前 必须仍返回 null（要单独注入验证）
3. 原有能算的九种说法一个都不能坏
4. 半个月后、半年后、一季度后 若纳入，结果须与语义一致
5. 金丝雀必须注入坏实现验证真会报红
6. 改完跑全量回归，所有命令 exit=0
