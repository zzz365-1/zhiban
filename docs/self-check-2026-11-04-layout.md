# 2026-11-04 布局与文案统一轮 自检记录

同学发来三张截图，要求按此前约定把界面改回上下分区，统一标签写法，
去掉大面积留白，内容多时允许滚动，并保证信息展示完整。
开发前的验收案例与预期写在 `docs/acceptance-cases-080-082.md`，
本文件只记实际跑出来的结果，明确区分实测通过和尚未验证。

## 一、改了什么

| 文件 | 改动 |
| --- | --- |
| `app/components/NoticeDetail.js` | 详情主体由左右分栏改为上下分区，原文在上最多占四成且自带滚动，解析结果在下占满整宽并自带滚动。折叠态由竖排文字条改为横向细条。原文输入框改为按内容自适应高度，去掉自身滚动条，标题栏吸顶并加分隔线，上下区间距收紧。文本域编号与高亮定位保持不变。 |
| `app/components/AnalysisPanel.js` | 事项清单整块从字段两列栅格里移出，成为栅格下方的整宽区块，分类仍留在字段区。字段标签行间距收紧一档。摘要与分类旁的两字母小标记改为中文「模型」。 |
| `app/page.js` | 来源标签 mixed 分支由「AI 辅助」改为「模型补充」，其余三个分支未动。 |
| `app/components/NewNoticeDialog.js` | 发布日期由浏览器原生日期控件改为受控文本输入，空态显示中文示例，填中文日期或标准写法都归一成页面原有的纯数字短横线写法，格式不对给中文提醒，留空立刻回传空串。弹窗原文输入框最小高度由 240 收到 120，超长后自身滚动。 |
| `scripts/test-round5.mjs` | 三条钉住旧控件的静态断言改成十条钉住新行为的断言，含一条反向断言。其余断言与末尾两条金丝雀未动。 |

代码全部由对话式 AI 产出，提示词归档 `prompts/080-*.md` 到 `prompts/086-*.md`，
AI 回复落在本机待审文件 `.ai-out-080.md` 到 `.ai-out-086.md`，不进仓库。
本机侧只做取证、提示词、落位、验收与文档。

  留空回传空值被改命中 1 条，中文示例占位被改命中 1 条。
  注入前单独做了干净副本，还原后与副本逐字节一致。
- `git diff --numstat` 删除行均未超过新增行两倍，无预期外新文件。

## 三、尚未验证与如实说明

- **`npm run build` 本轮未执行成功**。命令被本机安全守卫拦下，
  提示 `.next/types/validator.ts` 的批量删除需要确认，权限请求被拒绝。
  按工具要求没有重试，也没有改换等价命令绕过。
  替代证据是开发服务器实时编译无报错，浏览器 14 个场景全部正常渲染，
  `hasCompileError` 断言为假。生产构建这一项仍记为未验证，不能写成通过。
- **原文区没有恢复圆角卡片外壳**。085 收口时改用标题栏分隔线加白底与下区浅灰底的对比来分层级，
  最终截图里两级分界清楚，但与 022 之前的卡片形态不完全一样。
- **静态扫描仍有三处技术专有名词保留**：
  错误说明里的 `DEEPSEEK_API_KEY` 与 `JSON`，以及只写进 `_groundingDropped` 且不进界面的
  内部原因串「AI 值找不到出处」。它们是诊断内容与内部字段，不是界面标签，
  保留原名便于排错与对照环境变量。若后续要求文案全中文，需另开一轮。
- 事项卡里的 `A302`、`A201` 等是通知原文抽出的地点数据，不是标签，保留原样。
- 技术文档 PDF 成稿、演示视频成片、日期口径拍板、加载状态中间态，仍是全项目未完成项，本轮未碰。
