# 演示视频脚本，7 分 30 秒，1920×1080

配套文件 `docs/tech-doc-outline.md`。本脚本是**拍摄脚本**，不是成片。
录制参数：1920×1080、30fps、系统声音与麦克风分轨、字幕单独一层、不加速不剪辑掉失败画面。
脚本正文是分镜，末尾「开录前准备」是录制当天的操作卡；两者冲突时以代码与当场真实输出为准。

**连贯案例**用同一条通知从头走到尾，中间不换数据：

> 关于2026年国家助学金评审工作安排的通知
> 各班请于11月5日下午5点前将纸质申请表报送至学生工作处A302办公室。
> 评审会定于11月8日晚7点在行政楼A302会议室召开，请各班班长届时到场。

补充通知用这一条：

> 关于助学金评审会的补充通知
> 原定11月8日的助学金评审会调整至11月9日19:00，地点改为行政楼B201会议室，其余安排不变。

这两条是 `scripts/test-items.mjs`、`scripts/test-patch.mjs` 与 `docs/demo-notices.md` 里
真实跑过的素材，不是现场编的。所有界面名称按代码里的实际文案念。
